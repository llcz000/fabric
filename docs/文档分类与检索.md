## 唯一业务知识与双向影响

- 业务正文只能在[项目需求总览](project/项目需求总览.md)修改；[V2 AC 验收清单](product-master/product-master-v2-requirements.md)仅包含验收场景，不能新定义业务。
- 实时拓扑/反向依赖：`npm run knowledge:map`；按需求ID或项目相对路径追踪：`npm run knowledge:impact -- CUSTOMER-07`；当前变更范围：`npm run knowledge:changed`。
- 防止新增重复文档、丢失需求归属和无意恢复旧规则：`npm run knowledge:check`；源关系登记在`scripts/fabric-knowledge-registry.json`，治理规范见[知识维护规则](maintenance/知识维护规则.md)。
