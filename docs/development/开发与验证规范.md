# 开发与验证规范

> 文档定位：规范与手册｜主要读者：设计/开发/测试/运维及Agent。用途：按当前任务选择对应规范或运行方法。

更新：2026-10-15。规则来自当前源码与已有复盘；历史通过数量不作为现在的验证结果。

## 开始与结束

先读[项目现状](../project/项目现状.md)、对应领域设计及最近 1–2 篇[开发复盘](../retrospectives/README.md)。确认当前 Git 改动，保留其他工作。最小修改应解决明确问题；完成后把原因、修复、验证和剩余问题写到 `docs/retrospectives/development/`。

**每项任务交付前强制检查历史过程文档处置**：交付/复盘需写明`保留｜归档候选｜不适用`及其理由。功能仅本机编码/测试通过、但正式接线、真实MySQL、浏览器或回滚Gate未验收时，不能标记任务全面验收，也不能直接归档其唯一技术记录。仅当已完成约定验收，或旧记录被更准确的新文档替代且独有经验/开放Gate已迁入当前文档，方可走[归档Gate](../maintenance/知识维护规则.md#任务完成后的强制归档-gate)的逐文件哈希备份、只读验证、更新索引及受控移出流程。

## 必须延续的经验

- 预览、PNG、打印共用固定纸张 DOM；手机通过外层滚动查看。不要为导出重新建立布局或将克隆宽度硬设成 900px。
- 预览与 Excel 共用 `buildDocumentPrintModel` 的类型、字段与口径；变化在共享模型和两种输出的相关测试中验证。
- 定金单二维码问题先与样布单的有效路径比较；二维码角色、加载和捕获链路保持一致。
- 图片资产关联、软删除、回收与共享引用按现有生命周期处理；不要把临时访问 URL 当数据库字段。
- 路由测试覆盖真实 app 装配，特别是功能开关关闭后的传统行为、解析器隔离与鉴权。
- DDL 兼容性必须在实际目标数据库版本验证，模拟 SQL 测试不足以证明线上可以执行。
- 测试执行器使用本次独有 `tmp/tests-*`，等待子进程 close 后清理；不要恢复共享输出目录。当前执行器已采用 esbuild，旧 tsc 竞态说明只作为历史根因。
- Windows整库`node --test`默认可同时启动大量测试文件子进程，曾触发`spawn ENOMEM/UNKNOWN`，**不代表功能用例失败**。`scripts/run-ts-tests.mjs`默认使用`--test-concurrency=2`，允许显式`FABRIC_TEST_CONCURRENCY=1..4`；不能靠省略或跳过测试伪造全绿。TypeScript `Zone Allocation OOM`和业务TS报错也必须分别记录；若只能做局部`tsc`，不可将局部退出0写为完整`npm run lint`通过。
- 密码/密钥/连接文件不写入文档或日志，运行数据不能随清理知识库删除。

## 按变更选择验证

| 变更 | 项目已有命令 |
|---|---|
| TypeScript 与构建 | npm.cmd run lint；npm.cmd run build |
| 单元与集成行为 | npm.cmd run test:unit |
| 单据预览/图片导出 | npm.cmd run test:image-export |

| 鉴权、限流、上传、代理边界 | 构建后 npm.cmd run test:security |
| 完整交付门槛 | npm.cmd run test:all |
| 文档整理/历史归档 | node scripts/check-fabric-v2-doc-navigation.mjs；归档候选另跑node scripts/check-fabric-v2-doc-archive.mjs <review-plan.json>；技能/P0静态Gate与git diff --check |

源码入口：package.json、scripts/run-ts-tests.mjs、scripts/smoke-security.mjs、scripts/smoke-image-assets.mjs。命令通过后不因惯性重复执行；新的改动或失败再触发相关验证。

## 证据如何写

写清实际执行命令、时间、结果与环境。没有执行就写“未执行”；没有远程检查就写“未核验线上”。新增代码与测试存在、测试通过、提交推送、部署成功、导入业务数据是不同结果，逐一记录。


## UI设计与交付

默认按[UI规范](../ui-design/README.md)复用React并提供可交互预览，Stitch按需使用。仅实际操作Stitch远程页面时按[流程第8节](../product-master/product-master-v2-ui-iteration-workflow.md#8-stitch-画布与本地原型交付流程2026-10-11-生效)列预期页面，读最新HTML/截图并核对画布、保护用户修改；运行node scripts/check-stitch-review-delivery.mjs时使用最新真实快照。脚本不能代替实时视觉，React预览不要求额外画布。

## 已验证经验的适用边界

- 测试SQL替身按语句类型、参数和分页顺序精确匹配，不为让Mock通过改成事务外查重。数据库唯一/FK/锁/DECIMAL另经真库验收，见[合并复盘](../retrospectives/README.md)。
- 数据库危险操作先独立预置预期服务器身份，再校验实际UUID/库名与允许范围；不能将连接读到的身份直接当预期。只保护事务连接不足以保护认证读取，见[连接池复盘](../retrospectives/README.md)。
- 测试执行器结束后再串行运行lint/build，避免临时目录竞态；全量已通过且代码未改时，不因整理文档重复全套测试。
- 同主题在已有交付/复盘中更新当前结论和独有经验，不再按每轮测试数量拆新文档；历史证据标日期，状态只在当前进度登记。

## 历史经验提炼后的现行安全检查

- **真实数据库与事务**：事务内一次性验证引用、锁顺序、唯一键/外键和目标数据库身份；所有读写连接必须核验正确库，不以SQL Mock通过代替真实MySQL的并发、迁移和回滚结果。
- **高价值回归**：单据计价的逐匹/扣损/定金、跨权限读写、删除失败恢复、唯一单号、附件类型/大小/像素与XLSX真实解码、内网图片代理拦截、终止进程关闭连接池。仅在相关功能变化时针对性执行；不要照搬旧安全/业务断言。
- **草稿与网络异常**：取消/关闭不提交、保存失败恢复原草稿、上传分文件报告与幂等重试；按稳定ID处理跨页选择，禁止同一色卡其它条目被连带删除。
- **打印与图片导出**：固定纸张DOM与共享打印模型；窄屏/PNG/Excel保持布局边界，头部可收缩区域 `min-width:0`、长名称自动换行，不能用硬编码导出克隆900px替代正式版面。
- **发布**：冻结相同SHA的制品，线上运行态必须同时检查模式、真实存储和业务授权API；预检、上线、回退共用类型安全的状态契约。未知远端结果停止自动重试，先核状态和备份。

历史复盘和早期知识库中所有“当前待修复”的漏洞/路径只代表旧审计时点，不能作为今天新的需求、线上漏洞确认或权限放宽理由；以最新需求、当前代码及实际测试证据判断。
