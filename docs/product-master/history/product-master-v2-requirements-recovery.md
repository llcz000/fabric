## 3. 历史讨论中的三库结构

花型、面料分别维护主数据。产品关联一个花型和一个面料，再记录配色码、配色名称及产品图片。

```text
花型 patterns ──┐
                ├── 产品 products：花型 + 面料 + 配色码
面料 fabrics ──┘
```

### 3.1 花型库 patterns

| 字段 | 含义与历史讨论规则 |
| --- | --- |
| id | 内部 ID |
| pattern_no | 唯一花型编号；去首尾空格、英文字母转大写，字母数字，不允许横杠 |
| category_tags | 多选标签 JSON，0～10 个；候选值后续可微调 |
| pattern_image_asset_id | 花型原图资产 ID，可空 |
| remark | 备注 |
| is_active | 启用 / 停用 |
| created_at / updated_at | 创建与更新时间 |

历史标签候选：花卉、植物、条纹、格纹、几何、抽象、动物、佩斯利、民族、度假、波点、字母图文、肌理、其他。颜色归产品配色，面料属性归面料，不混入花型分类标签。

### 3.2 面料库 fabrics

| 字段 | 含义与历史讨论规则 |
| --- | --- |
| id | 内部 ID |
| fabric_no | 唯一面料品号 |
| fabric_name | 面料品名；用户最后明确要求增加，并在产品里展示 |
| composition | 成分 |
| weight_value | 克重数值 |
| weight_unit | gsm / mm；分别表示克/平方米与姆米 |
| width_value | 门幅，固定按 cm |
| remark | 备注 |
| is_active | 启用 / 停用 |
| created_at / updated_at | 创建与更新时间 |

品名、成分、克重、门幅由面料库维护。产品通过 fabric_id 读取和展示，不在产品里重复存储这些属性。

### 3.3 产品库 products

| 字段 | 含义与历史讨论规则 |
| --- | --- |
| id | 内部永久 ID |
| product_no | 系统自动生成的唯一产品货号 |
| pattern_id | 关联花型 |
| fabric_id | 关联面料 |
| color_code | 配色码，参与货号与组合唯一性 |
| color_name | 配色名称，可空，不参与唯一性 |
| fabric_image_asset_ids | 面料大图资产 ID 数组，0～10 张 |
| detail_image_asset_ids | 细节图资产 ID 数组，0～10 张 |
| effect_image_asset_ids | 效果图资产 ID 数组，0～10 张 |
| remark | 备注 |
| is_active | 启用 / 停用 |
| created_at / updated_at | 创建与更新时间 |

产品货号：花型编号 + "-" + 面料品号 + "-" + 配色码。例如 G0812-S23-A。

组合唯一性：(pattern_id, fabric_id, color_code)；货号本身也唯一。编号组成部分不允许包含分隔横杠。系统生成货号，不提供普通手工货号输入框。

## 4. 历史讨论中的图片和页面规则

- 用户明确修正：产品列表只显示产品自己的面料大图；没有则显示统一缺省状态，不使用花型图代替。
- 产品三类图片各最多 10 张，数组顺序代表展示顺序，每类第一张为该类主图。
- 花型原图归花型库，不作为每个产品重复上传的第四类图片。
- 复用 image_assets，存资产 ID 而非 COS URL；保存与解除关联需维护资产引用。
- 产品列表展示组合后的面料品名、成分、克重、门幅及花型标签。
- 花型库历史交互建议：列表 + 新建/编辑抽屉。
- 面料库历史交互建议：行编辑，明确保存 / 取消，不逐字符自动写库。
- 产品历史交互建议：独立新增/编辑页，选择花型、面料，填写配色，预览自动货号，管理图片。
- 产品编辑时面料属性只读，提供编辑面料资料入口。

## 5. 历史讨论中的生命周期与边界

以下规则在历史助手回复中提出，应在本次需求整理中区分建议与最终确认：

- 已被产品引用的花型与面料不能删除，只能停用。
- 已被引用的花型编号和面料品号在普通编辑中锁定；未引用时可修改。
- 无引用记录删除前二次确认。
- 新业务可选产品同时要求产品、花型、面料处于启用状态。
- 产品配色码修改时预览货号变化，并检查冲突；正式订单、二维码关联后需进一步明确身份修改规则。
- 不做审核字段、审计日志或历史单据迁移，是历史会话末尾总结的范围；不据此修改现有其他模块。
