## 已实现

| 需求 | 当前行为 |
|---|---|
| 文件夹与多文件导入 | 两个明确入口；目录包含子目录，仅按最终文件名识别母版/数字配色。取消选择保留批次，重选替换批次，导入中禁止更换；不支持目录时可多选文件。跨目录同号全部报冲突，逐项反馈，沿用20MB、不覆盖、失败暂停同母版后续及其他母版继续 |
| 轻量建档与复用 | 内部客户档案页支持检索/筛选、公司/个人、开票抬头、多品牌、联系、渠道、地区和按面料类别的价格偏好。快速建档只需名称和电话/微信之一；开票、品牌、预算与评级可后补，未知不补零 |
| 选样关联 | 新建选样选择已有客户或快速建档，两者同事务并支持幂等重试。旧单可人工确认关联、更改或解除；保留原名称、扫码来源和寄样/跟进。关联版本避免并发覆盖，解除保留版本记录，不能同名自动合并 |
| 归属和协作 | 管理员全量，业务员本人/明确授权；协作区分只读、可编辑，负责人/管理员维护协作，管理员转移负责人。旧单未关联时维持原授权；已关联选样的目录、读取、扫码、人工加入/移除、状态和寄样/跟进复核当前客户权限，旧授权不能绕过撤权 |
| 客户维系 | 客户详情汇总选样、寄样、反馈及联系；人工等级/阶段有理由。跟进可生成有日期或未定日期待办，支持今日/逾期/寄样待反馈、完成/取消和历史。上海日期计算跨日状态，不以选样/寄样冒充成交 |
| 归档和运行时 | 归档保留资料和历史，停止新关联业务。启动只验schema，不自动建表；完全未安装客户表时只关闭新功能。已有客户schema损坏时选样入口安全拒绝，避免退回旧授权绕过客户限制 |

新客户结构为七张加法表；联系人、品牌和价格偏好保存在客户的结构化JSON中，由严格模型统一校验；客户—选样关联使用独立关系表，解除保留版本，未ALTER既有选样表。此处是对早期工程草案的实现收敛，业务字段、关系和验收要求保持。
