## 实现与代码定位

| 主题 | 代码与保留的实现边界 |
|---|---|
| 母版/数字配色 | server/product-master/patternMasters.ts、colorwayIdentity.ts；母版稳定ID，持久计数器+行锁，配色永久锁号不复用；母版改号先锁子版本再查产品/色卡引用 |
| 共享题材/颜色标签 | sharedTags.ts及Routes；同维NFKC/大小写规范化唯一；0～10关联；归档已有可追溯、不允许新挂；管理员改名核对影响数、合并去重并回滚，锁目标后锁标签 |
| 面料 | fabrics.ts及Routes；品号唯一；克重数值/单位同设同空、gsm/mm不换算、门幅cm、空值不造0；产品/色卡引用锁身份和删除，普通描述可更正；DECIMAL精度与服务校验一致 |
| 产品与图片 | productsV2.ts及Routes；服务端生成母版-配色-面料货号、组合唯一、expectedRowVersion CAS；已开单锁身份/禁删；三类图各0～10，字段/关联/顺序/ref_count同事务，缺省不传images保留、显式空布局解除；最后引用进入延迟回收，不能直接删共享资产 |
| 综合查询 | productSearch.ts；货号/品名独立AND，题材/颜色维内OR、跨维AND；COUNT与页查询共用全库条件、EXISTS去重、稳定排序；非空页5条SELECT，当前页批量读标签/图数量，无N+1；归档标签保留显示 |
| 权限与错误 | 每次Bearer校验、写事务内重查user/session/grant；参数化SQL/字面通配转义；400/401/403/404/409/503安全JSON，不回显内部SQL |

所有字段值/数量以[唯一需求](product-master-v2-requirements.md)和当前源码为准。列表产品启用与开单四级可选性不同；暂不供样不应污染订单选择。

## 真实验收与限制

2026-10-13 scripts/test-v2-product-master-mysql.ts在固定空隔离库fabric_v2_test_20261013_p3integration执行MySQL8.0.46实测。先限定表名并核对全部空表，显式ACK后才写；每事务连接SELECT DATABASE()，末尾仅清当次夹具并核对归零，未写生产fabric_db。

已验：9路并发配色分配；8路同组合创建仅1成功其余409；标签归档/合并；面料/订单引用与row_version；共享图计数2→1→0与缺资产整笔回滚；真实HTTP登录/筛选；100母版×3配色×7面料=2,100条分页。关键词B0只命中99个母版曾令预期2079/2100失配，修正夹具而非改SQL。同机Socket查询P95记录28.4ms，不能当办公网络+React端到端1秒验收。
