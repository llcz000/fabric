## 核心实现

| 环节 | 保留的契约与定位 |
|---|---|
| 解析 | server/product-master/fabricExcelPreview.ts；只支持xlsx，ExcelJS；8MB/20工作表/3000行/64列上限，七列、工作表/表头/人工映射；编号文本保前导0，不猜补数字单元格；公式/特殊单元格拒绝，不执行 |
| 单位与重复 | gsm/mm只标准化不换算，缺单位人工指定、冲突错误；门幅cm、空规格null；文件内规范化品号重复整组跳过、其余合法行继续；已有品号默认跳过且可查看差异 |
| 预览凭证 | fabricExcelImport.ts；服务端持解析与已有记录快照，绑定用户+session的15分钟随机一次性令牌；新预览使旧令牌失效，改变文件/工作表/表头/映射/单位需重新预览 |
| 提交与并发 | commit仅收token/confirm/行号，不信客户端行内容；重查实时授权，仅admin显式选择更新；锁记录比旧快照，变化失败要求重预览，新冲突跳过；每行事务，单行失败回滚余行继续；更新空字段保留旧值，不改身份/启停 |
| HTTP与界面 | fabricExcelImportRoutes.ts、FabricImportV2.tsx、fabricImportModel.ts；JSON/base64的8MB文件/12MB请求上限，安全错误；八列真实行号预览、差异、逐行勾选、二次确认及新增/更新/跳过/失败结果 |
| 窄屏 | 表格内部横滚、role=region/aria-label/tabIndex=0，320/360提示可左右滑动；确认区可操作，不裁列或让整页溢出 |
