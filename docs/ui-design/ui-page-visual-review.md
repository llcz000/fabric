# Fabric 正式页面视觉复查方法

> 仅提供审美与页面核对方法；**唯一交付流程和证据门禁**是 [UI Gate](ux-delivery-gate.md)，逐项质量断言见 [UI 检查清单](ui-review-checklist.md)。不要在这里重复验收状态、命令、流程或业务规则。

1. **先看真页面**：读取当前正式 React 组件、局部 CSS 与实际业务视图，对照最新验收截图和受影响弹窗；不可仅评审孤立组件样板。
2. **一轮审美校对**：审查标题冗余、文案信息密度、列宽、字体层级、筛选/分页间距、主次按钮与关闭操作；优先复用共享组件，局部样式只作用于目标页面。
3. **真实尺寸并排核对**：桌面和窄屏分别打开实际 CSS 页面，覆盖主区域、弹窗、空态与较长内容；对比同一业务系统的视觉一致性，发现问题本轮修复而不追加第二份交付报告。
4. **特殊情况**：客户分享页关注图像主次和微信触屏；Stitch 仅实际使用远程画布时核对用户修改。视觉通过须有对应真实截图，不以自动测试通过替代人工审美。

交付证据直接写入 UI Gate 既有制品，不按日期新建评审总结。
