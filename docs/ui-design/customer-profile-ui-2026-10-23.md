## 范围与设计

活动源 `.agent-workspaces/v2-quality-20261020`。复用 `CustomerWorkspace`、`CustomerProfileForm`、客户 model 与原确认组件；未调用 Stitch/Figma。已实际读取 Fabric UI Design、UI/UX QA、UI UX Pro Max、Frontend Design、Web Interface Guidelines 与 Superpowers 的相关流程技能；运行局部 UX 查询并读取官方最新 Web Interface Guidelines。UI preflight PASS，根目录权威规范未修改。

- **当前为用户三轮修订**：在二轮弹窗方案上继续去除开票抬头与价格口径选项，压缩普通桌面编辑至无需滚动；一、二轮证据保留，均未作为用户签收。
- 列表更紧凑，每行直接提供“详情 / 编辑 / 删除”；编辑服从canEdit，删除只对管理员canDelete显示。保留服务器筛选/分页；正常状态无刷新档案操作，打开窗口重新读取详情，保存/删除后列表自动更新；取消浏览不重新读取列表。
- **详情弹窗**：用只读文本而非一屏禁用输入框；仅在详情里用“客户资料 / 业务历史”两个Tab，支持方向键、Home/End及ARIA选中状态。打开原记录前关闭详情窗口。
- **编辑/新建弹窗**：直接表单，不放Tab。品牌并入基础资料的单一输入，不提供添加/移除多品牌；存量多品牌未编辑时保留，明确修改品牌后按单品牌保存。基础资料三列，桌面按基础/联系人、偏好/回访、价格三行排布；普通单联系人/单价格资料在1366×768、1440×900和1280×720均无需滚动，字段和保存按钮完整显示；额外多行及窄屏保留安全纵向滚动。移除层层卡片边框；底部取消/保存固定可达。
- **字段精简**：开票抬头不再编辑或展示，旧数据保留；价格每行仅面料类别、价格范围、备注，统一显示元/米，不再选择币种、单位、含税口径。新增或明确编辑价格使用CNY/metre/unknown，未修改的旧价格元数据不被无关编辑清空，不做汇率换算/迁移。常用面料默认仅显示已选项，输入后显示匹配候选。
- **删除**：直接从列表打开一次危险确认，实时读取关联数和版本；取消/Esc恢复原行按钮焦点。脏态的×、取消和Esc同样受丢弃确认保护，连续点击不堆叠多次确认。
- 弹窗与Tab分工：弹窗保留列表筛选/分页/位置和触发焦点；Tab只用来分隔同一客户的只读资料与业务历史，不作为编辑步骤。列表/详情权限失效清除旧私有数据；保存冲突保留草稿。

## 用户追加缺陷与证据

客户选样删除采用 `deleted_at` 逻辑删除，旧删除预览直接 COUNT `customer_session_links`，把已删除选样也计入，能出现列表空而提示2张。现在 JOIN 实际选样并限定 `deleted_at IS NULL`，全部删除后计0。业务历史的反馈分支同步过滤已删除选样，避免跳转到不可访问记录。保留选样、反馈、关联表和名称快照，不执行数据清理或迁移。

先运行失败回归：2张已删除＋1张关闭未删，旧实现误计3（期望1）；已删除选样反馈仍显示。修正后专项覆盖1→0、关闭仍计数、客户删除后原历史和关联行仍保留。证据在活动源 `artifacts/customer-ui-20261023/deletion-red.log` 与 `unit-verified.log`。
