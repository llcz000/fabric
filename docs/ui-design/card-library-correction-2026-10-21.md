# 色卡列表 UI 审阅纠偏（2026-10-21）

## 用户反馈与责任界限
用户明确指出：先前展示的“列设置/色卡列表”并非可接受的最终界面；比线上不好，品名列过宽，操作按钮拥挤，表头排序不实用应去掉。
**此前测试页不代表正式最终版，也未获用户批准。** 原因确认：演示夹具未引入正式 `v2Experience.css`，且 `shareEnabled=false` 导致分享操作缺席，令演示与线上活动组件视觉/操作不符。后续 UI 验收不允许再将抽象控件夹具冒充真实业务页。

## 实际改进
- 在真实活动组件 `src/components/product-master-v2/SampleCardTable.tsx` 中取消**色卡列表专属**表头排序。仍沿用原后端分页顺序；面料库、产品库排序行为未改。
- 保留线上沿用的 `ColumnSettingsMenu` 及其列隐藏、恢复默认行为，不引入另一套“列设置”样式或业务状态。
- 色卡列表列宽：色卡号160px、品名166px（过长以省略号显示并用 title 查看完整）、成分自适应、克重100px、门幅96px、操作206px；最小表宽970px，窄窗口由列表区域横向滚动。
- 操作采用一行 Flex，四个36px触控图标按钮间隔8px，操作列固定最小空间，不依赖压缩各按钮解决窄屏。
- 新版真实预览入口 `http://127.0.0.1:52991/ui-ux-internal-cards.html`；直接复用**正式业务 React 组件和正式 CSS**，开启“分享花型产品”图标，使用3条明确标识的模拟记录，未连接真实后端。先前 `ui-ux-internal-chrome.html` 仅是独立控件行为夹具，不应再作为色卡最终验收页。
