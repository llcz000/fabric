# 色卡客户分享：微信手机 H5 规范

> 现行客户页规范。业务范围以[项目需求](../project/项目需求总览.md#v2-selection)为准，发布与待验只查[项目现状](../project/项目现状.md)。旧测试流水及预览地址存于[恢复包](../maintenance/文档整合与恢复.md)，不证明当前设备可用。

## 入口与数据边界

内部工作台仅员工使用；色卡 `/c/<token>` 打开的页面面向客户。正式源码从唯一根目录 `D:/fabric` 定位：`src/components/customer-share/PublicCardGallery.tsx`、`PublicProductImage.tsx`、`PublicPatternPage.tsx`。不再进入旧内嵌工作区。

公开请求必须保持现有 token 校验、当前公开许可、DTO 白名单和图片二次授权；不因手机布局修改放宽权限。客户仅看到本次获准产品/色卡范围内的三类图片和成分等许可字段，不泄漏内部客户、价格、管理操作或其它未获准产品。

## 手机交互要求

- 375～430px 常见屏宽下首屏身份、配色和资料可读；不出现整页横向溢出、大 Hero 或内部操作。
- 配色导航触控目标足够，三类图片归属正确；缺图不从其它配色借用，当前类别按需加载。
- 图片等比展示；放大、关闭、失败重试、返回及焦点恢复可用，弹层适配手机可视高度和安全区域。
- 首屏加载与长列表性能单独核对，不以桌面静态截图或缓存命中推断手机弱网体验。

## 验收与发布

浏览器触屏/微信 UA 模拟、真实 iOS/Android 微信、真实公网授权/COS 及用户视觉接受分别记录。未在微信实机打开真实有效 HTTPS 分享链接并检查首屏、配色、缺图/失效、弱网、放大关闭及返回，不得标记微信真机 PASS。演示地址和模拟图片不能发送客户作为正式成果。

改动前执行 UI preflight，按影响范围完成真实组件视觉、浏览器和工程验证；发布使用[统一工具](../operations/统一发布工具.md)，仍须明确授权。历史通过数、旧依赖缺失/OOM 及旧发布记录不作为当前通过或失败结论。
