# Component Rules：组件与交互规范

> 文档定位：规范与手册｜主要读者：设计/开发/测试/运维及Agent。用途：按当前任务选择对应规范或运行方法。

业务数值与权限以[唯一业务需求](../project/项目需求总览.md)为准；本文件只规定已有 UI 组件如何表达，不独立改变业务权限。

源码路径均相对当前活动应用根目录；正式代码入口见[项目设计](../project/项目设计.md)及[产品主数据源码索引](../product-master/README.md)。

## 复用已有实现

2026-10-18补充：文件选择器cancel不能当成退出父对话框，父onCancel按target/currentTarget隔离，仍保留真正脏表单退出确认。已选产品表勾选以稳定条目ID绑定，一行一框，不能用同来源色卡ID绑定多行；页内全选与跨页保留分开，移除动作统一入口并明确只处理所选货号。部分保存流程只锁已确认成功部分，明确失败维度仍可修订重试。

单据接线沿用已发布页面的基本信息、明细表、实时汇总和默认收起的签署联系信息；没有明确需求不得借接线新增业务控件或替换布局。选品验收必须看到带出的只读规格，金额验收覆盖实时输入、保存回读、预览同表合并汇总和实际导出；接口200、标签存在或自动截图不能代签用户视觉接受。见[2026-10-18纠偏复盘](../retrospectives/README.md)。

## 表格、筛选与分页

- 产品列数、顺序和可见性以最新项目需求及当前 `ProductCatalogV2.tsx` 的列定义为准，不在规范复制固定列数；保留产品自身备注和关联色卡，禁止从母版或面料替代产品备注。
- 产品库货号和品名是独立输入，组合为 AND，与当前有效筛选条件共同作用，不恢复已取消的启停控件。花型库按现行题材多选，保留自定义题材；不恢复已取消的颜色标签及配色序号筛选入口。按当前需求和 model 定义请求，禁止只过滤当前页数据。
- 变更筛选重置分页；加载时保留用户输入，旧响应不能覆盖新搜索。空库提示创建入口，无匹配提示清除筛选，失败给重试，不把三者混成“暂无数据”。
- 长文字允许截断，必须可查看完整备注；行操作有可读名称，不依赖悬停图标。多选/导出明确“当前页”或实际选择集合，不暗示自动选中全部匹配。
- 客户选样首次看图选款与人工补选复用同一界面：每卡一行、配色缩略图与编号直接展示，不设展开/收起；默认不选，本单已选项标识且禁用重复勾选；主动全选本卡或逐款选择后仅一个加入按钮提交，零选禁用。色卡搜索集中在一个入口；失败保留选择，关闭/Esc不提交待选项。业务语义以 V2-09/V2-10 为准。

2026-10-19用户修订：三库搜索输入框统一高度、字号、边框与筛选区样式；花型编号搜索与题材筛选分组，保留原筛选语义。花型库导出暂移除。面料、产品的“导出筛选结果”仍是全部匹配记录，捕获点击时的条件并去掉分页，不导出图片/操作列；服务端显式白名单，保留文本编号/单位/空值，不将DTO及内部路径或临时签名直接写入文件。筛选过程中改变条件不更改已发起的导出。

## V2 内部业务页按钮与反馈

- V2 内部业务页面统一沿用单据列表的品牌蓝 #0053da、次级边框 #c3c6d7、8px 圆角和同一组线性图标；主按钮、次按钮、轻操作、危险操作、纯图标按钮分别使用共享语义样式，不直接复用客户档案表单的 sky-blue 按钮配色。
- 同一操作区保持清晰主次：客户选样首页以“新建选样单”为主操作，搜索/多选/单条导出为次操作；选样明细以“继续扫码”为主操作，人工补选和导出为次操作；聚焦扫码页的扫码入口为主操作，看图选款为次操作。不得为了颜色统一改变业务路径。
- 桌面常规按钮触控高度至少40px，手机按钮和图标入口至少44px；图标与文字间距、边框、hover、pressed、focus-visible、disabled 状态统一。纯图标按钮必须有明确 aria-label，多选按钮暴露 aria-pressed。
- 导出成功统一使用全局自动消失 Toast，不在页面留下常驻成功条；失败提示保留在相关区域并提供可重试路径。进行中的扫码/保存状态仍可留在操作上下文内。

## 表单、候选与对话框

2026-10-18补选与数值输入：人工补选独立模态，失败/成功在模态内可见，保留勾选和关闭焦点，写入锁关闭。选样入口与历史记录维护遵循 V2-09 / AC-163～164：扫码聚焦页、首页同页客户选择和明细维护不再沿用旧“客户必填弹窗”或“关闭即只读”规则；取消不创建，保存中防重入；色卡库直接在列表显示真实组合的全部配色thumbnail＋编号，移除查看花型弹窗且不预取原图。系统登录默认大盘，目录明确选样单内扫码路径；自动模拟不替代Android设备验收。数字默认0可空白，但保留未完成原文并明确校验，不静默变0；修订后清旧错误，保存前校验继续生效。

字段有标签、单位和必要提示；null 展示为“—”或空输入，不伪造为 0。错误在相关字段附近显示，保留已输入内容。保存中阻止重复提交；失败保持草稿；遇到版本冲突解释重新加载/核对路径，避免静默覆盖。

对话框有标题、可见关闭入口、合理键盘焦点与退出后焦点恢复。未保存内容关闭应按已有交互约定处理。图标按钮有 aria-label，候选列表可键盘操作，状态提示可被辅助技术读取。不能仅靠禁用按钮表达业务拒绝原因。

销售逐匹默认10个位置且可追加，空位置不计匹数，毛米数由有效匹合计。输入未完成的文本必须保留并阻止保存，不能依赖原生number框将其清空；已有无分匹资料在实际修改前保留原米数。

单据财务控件按DOC-05～08只显示适用项，金额与百分比标签分明；未完成定金文本保留并阻止提交，不能静默当0。隐藏字段不因无关编辑被重置：样布PATCH省略deposit，定金PATCH省略settled；历史原值保留，显示按现行类型规则投影。预览和Excel使用同一支付计算与汇总模型。

数字配色在成功保存后永久只读，单调递增、删除不复用；未保存草稿取消不占号。前端下一号是预览，最终以服务端结果为准，不按现有数量或最大现存编号“补洞”。

实体色卡新增只选花型母版和面料品号。候选分别只显示母版编号/品号（面料仍支持品号或品名检索）；配色图、面料品名/成分/规格在选后校对区只读显示。不要恢复已取消的标签预览、标签下载或色卡导入。

## 图片与文件

模特图库使用保留全图的 display 预览，使用统一3:4竖向画框、居中等比contain及浅色留白，不用已中心裁切的 thumbnail；资料区保留编号/类别/角度和单行备注，空备注预留同等行高，操作位置对齐，不展示像素/参考尺寸及未校准提示；换装选择模特同样保持全图。模特导入结果复用全局 toast，支持关闭和自动消失，不在页面常驻成功计数；部分失败说明成功张数和失败文件/原因。

花型库、面料库的关联产品弹窗按PRD-08 / AC-161直接展示每行配色的等比thumbnail，桌面保持紧凑图列、手机在资料左侧，保留完整编号和单行面料信息。图片请求按当前页资产去重并可取消，缺图/加载/失败分开表达，失败可重试且不阻断产品读取，不因查看缩略图请求原图。

配色原图属于配色版本，产品图片分面料展示/细节/效果三类，每类 0～10 张；不要重新采用历史“总共20张”的规则。数量与上传限制以当前需求和后端为准。上传、成功、失败、移除关联区分反馈；替换当前关联不允许误删其他对象正在引用的共享资产。

产品列表“产品图”用三类Tab查看原图，仅当前类按需加载，未看类别不预取；当前弹窗保留已加载图片，切回复用，关闭即清理本次缓存。Tab支持方向键/Home/End，焦点圈应覆盖可见且tabIndex非负的按钮和面板，不能纳入隐藏面板或非活动Tab。花型/产品列表仍仅加载缩略图，点击才取同资产原图。

面料导入只接收 XLSX；字段冲突和管理员更新权限保持现有业务方案。色卡多选导出 色卡编号 / 品名 / 成分 / 克重 / 门幅 / 二维码 六列，二维码 为原始编码纯文本；页面二维码与导出文本源于同一 payload。导出按钮成功必须以真实文件可下载并核验内容为证据。

## 状态、权限与历史

| 情况 | UI 要表达 | 验证边界 |
|---|---|---|
| 当前精简范围 | 不恢复已取消的常规启停、暂不供样及寄样跟进入口 | 按需求总览 LITE/CUSTOMER 条款核对 |
| 色卡资料变更 | 显示需重新打印，运营逐卡确认 | 旧确认不能清除新修订号待印 |
| 色卡删除重建 | 旧卡已失效，同组合新卡为新身份 | 旧码永久作废，不恢复旧链接 |
| 选样资料 | 读取最新主数据，保留选择事实；正常无有效标识 | 根据当前服务端和本次真实验收判断，不沿用旧实现状态 |
| 已保存三种单据 | 保存属性口径和历史手工明细保护 | 不能套用选样实时刷新的规则 |
| 管理权限缺失 | 只读/无权反馈与实际角色一致 | 前端隐藏操作不替代服务端检查 |

编号表头全局排序遵循PAT-03/V2-03/V2-08：花型按母版号数字，产品按母版数字及配色数字、色卡按母版数字，忽略面料品号排序但保留完整编号及独立行；先排序再分页，切换回第一页，未选排序保持原默认。产品其它已有列的本页排序须在提示中区分。

客户选样列表按V2-09显示联系人姓名，桌面分列、360px客户/日期与联系人/计数紧凑两行，长值可完整查看且不挤掉导出/更多；联系人取当前档案；客户名称按 CUSTOMER-04 读取。档案改名遇到重名时，在原编辑弹窗提示并保留已填内容。客户档案只改“详细地址”文案保留原值；删除关联未删选样的客户时，按CUSTOMER-08显示数量与先删选样提示，不出现仍可继续删除的确认按钮。

历史选样的列表更多按服务端 canDelete 判定，明细编辑按 canManage 判定；关联客户删除/旧归档不自动隐藏有权人员的单独删除入口，不能用编辑只读状态替代删除权限。删除仍确认客户与日期，取消/Esc不写入，失败保留原记录；具体角色与数据保留语义以 V2-09 为准。

管理员和业务员的功能权限按现行 AUTH/CUSTOMER 要求逐项映射；不因旧协作授权数据恢复客户协作界面。新建/更换单据明细的管理员手工例外不扩大给业务员。客户公开花型分享与登录业务员扫实体色卡选样是两个入口，不混用公开范围。

2026-10-18手机返回与登录：浏览器返回优先派发弹窗原生cancel，保留已有写入锁/弃稿确认；无弹窗离开先确认，用户取消不得清dirty或重挂表单。历史只保留一对同URL守卫，刷新复用，前进/BFCache恢复重新布防，明确确认后允许离开。恢复登录只缓存token及固定截止时间，每次重开仍校验/me；主动退出/401/过期跨标签清理，异步完成清理必须比对发起token，不覆盖新身份；不得存密码或借本功能延长会话。

选样明细按实际色卡ID归并行，来源卡及面料规格只显示一次，行内直接排列已选配色图与完整花型配色编号，不显示产品货号及其悬浮提示；不同面料、新旧卡身份分开，所有历史来源保留且单产品只一处移除框。明细顶部提供整单“导出 Excel”，与首页共享导出规则，不将待移除勾选解释为导出范围；只读可导出、空单禁用、失败保留选择可重试。按卡分页前取齐既有产品页并核对一致性，图片签名分批去重获取thumbnail，异步结果不得跨客户回填；缺图/失败不影响勾选移除。

2026-10-18选样创建日期：客户目录在客户列后显示创建时间，采用数据库实际创建日期YYYY-MM-DD，日期单元格不换行，不显示时分；旧响应缺字段显示—，不以当前日期补造。

2026-10-19花型与实体色卡列表：花型按created_at DESC、id DESC稳定分页；色卡二维码改为操作中的“查看二维码”，列表不渲染小二维码或专列，点击复用响应式大图dialog，关闭/Esc返回原操作焦点；Excel六列与编码不变。

2026-10-19定金品名与地址：库内定金品名列只显示品名，隐藏规格副文案但不清除快照；定金预览固定地址栏，空白留填、已填显示，支持换行并在PNG/打印Excel保留；其它单据与默认收起联系信息保持。
