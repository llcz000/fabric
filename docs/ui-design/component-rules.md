# Component Rules：组件与交互规范

> 文档定位：规范与手册｜主要读者：设计/开发/测试/运维及Agent。用途：按当前任务选择对应规范或运行方法。

版本：0.1｜2026-10-14。业务数值和权限最终引用 [当前需求](../product-master/product-master-v2-requirements.md)；此文档规定 UI 如何表达与实现它们。

## 复用已有实现

2026-10-18补充：文件选择器cancel不能当成退出父对话框，父onCancel按target/currentTarget隔离，仍保留真正脏表单退出确认。已选产品表勾选以稳定条目ID绑定，一行一框，不能用同来源色卡ID绑定多行；页内全选与跨页保留分开，移除动作统一入口并明确只处理所选货号。部分保存流程只锁已确认成功部分，明确失败维度仍可修订重试。

单据接线沿用已发布页面的基本信息、明细表、实时汇总和默认收起的签署联系信息；没有明确需求不得借接线新增业务控件或替换布局。选品验收必须看到带出的只读规格，金额验收覆盖实时输入、保存回读、预览同表合并汇总和实际导出；接口200、标签存在或自动截图不能代签用户视觉接受。见[2026-10-18纠偏复盘](../retrospectives/development/2026-10-16-document-query.md#2026-10-18-单据布局偏离已发布版用户验收纠偏)。

## 表格、筛选与分页

- 产品列表按2026-10-16要求暂为10列：花型图、货号、品名、成分、克重、门幅 / cm、图片数量、备注、启用状态、操作。题材/颜色列及筛选暂去掉，底层关联保留。备注位于图片数量后，产品备注不从母版或面料替代。
- 产品库货号和品名是独立输入，组合为 AND，与启停共同筛选。花型库题材和颜色标签同属花型级、分别多选，各维度内部 OR，跨维 AND；列表各自独立成列，去掉配色序号筛选入口。按当前需求和 model 定义请求，禁止只过滤当前页数据。
- 变更筛选重置分页；加载时保留用户输入，旧响应不能覆盖新搜索。空库提示创建入口，无匹配提示清除筛选，失败给重试，不把三者混成“暂无数据”。
- 长文字允许截断，必须可查看完整备注；行操作有可读名称，不依赖悬停图标。多选/导出明确“当前页”或实际选择集合，不暗示自动选中全部匹配。
- 客户选样补选按2026-10-17追加要求：首列色卡编号直接点击展开/收起，无额外展开文案；展开为紧凑花型缩略图＋花型编号勾选项，默认全选，父复选框表达全选/部分/全不选。每卡只留“加入”，按当前勾选提交，零勾选禁用，无独立子集按钮。缩略图仅展开后加载；失败保留勾选，不提供无卡产品或按货号补选入口。

三库“导出筛选结果”是全部匹配记录，捕获点击时的条件并去掉分页，不导出图片/操作列；服务端显式白名单，保留文本编号/单位/空值，不将DTO及内部路径或临时签名直接写入文件。筛选过程中改变条件不更改已发起的导出。

## 表单、候选与对话框

2026-10-18补选与数值输入：辅助选品使用独立模态，反馈必须在模态内可见，保留失败勾选、关闭焦点返回及写入锁；桌面可隐藏扫码区，移动端保留照片解码和显式确认；“扫码加入”作为立即打开拍照/选图的可点入口，识别后另显“确认加入”，避免把未识别时禁用的提交按钮当扫码入口。拍照/相册使用直接可点击且可键盘聚焦的原生file输入，独立相册无capture作为回退；不能仅按viewport宽度把触屏手机的扫码区隐藏。系统登录默认大盘，目录应明确选样单内扫码路径；Edge chooser通过不等于Android宿主相机通过。业务数字默认0可显示空白，但应保留未完成原文并明确校验，不能静默变0；修订后清旧保存错误，当前有效性和保存前校验继续生效。

字段有标签、单位和必要提示；null 展示为“—”或空输入，不伪造为 0。错误在相关字段附近显示，保留已输入内容。保存中阻止重复提交；失败保持草稿；遇到版本冲突解释重新加载/核对路径，避免静默覆盖。

对话框有标题、可见关闭入口、合理键盘焦点与退出后焦点恢复。未保存内容关闭应按已有交互约定处理。图标按钮有 aria-label，候选列表可键盘操作，状态提示可被辅助技术读取。不能仅靠禁用按钮表达业务拒绝原因。

销售逐匹默认10个位置且可追加，空位置不计匹数，毛米数由有效匹合计。输入未完成的文本必须保留并阻止保存，不能依赖原生number框将其清空；已有无分匹资料在实际修改前保留原米数。

单据财务控件按DOC-05～08只显示适用项，金额与百分比标签分明；未完成定金文本保留并阻止提交，不能静默当0。隐藏字段不因无关编辑被重置：样布PATCH省略deposit，定金PATCH省略settled；历史原值保留，显示按现行类型规则投影。预览和Excel使用同一支付计算与汇总模型。

数字配色在成功保存后永久只读，单调递增、删除不复用；未保存草稿取消不占号。前端下一号是预览，最终以服务端结果为准，不按现有数量或最大现存编号“补洞”。

实体色卡新增只选花型母版和面料品号。候选分别只显示母版编号/品号（面料仍支持品号或品名检索）；配色图、面料品名/成分/规格在选后校对区只读显示。不要恢复已取消的标签预览、标签下载或色卡导入。

## 图片与文件

配色原图属于配色版本，产品图片分面料展示/细节/效果三类，每类 0～10 张；不要重新采用历史“总共20张”的规则。数量与上传限制以当前需求和后端为准。上传、成功、失败、移除关联区分反馈；替换当前关联不允许误删其他对象正在引用的共享资产。

产品列表“产品图”用三类Tab查看原图，仅当前类按需加载，未看类别不预取；当前弹窗保留已加载图片，切回复用，关闭即清理本次缓存。Tab支持方向键/Home/End，焦点圈应覆盖可见且tabIndex非负的按钮和面板，不能纳入隐藏面板或非活动Tab。花型/产品列表仍仅加载缩略图，点击才取同资产原图。

面料导入只接收 XLSX；字段冲突和管理员更新权限保持现有业务方案。色卡多选导出 色卡编号 / 品名 / 成分 / 克重 / 门幅 / 二维码 六列，二维码 为原始编码纯文本；页面二维码与导出文本源于同一 payload。导出按钮成功必须以真实文件可下载并核验内容为证据。

## 状态、权限与历史

| 情况 | UI 要表达 | 验证边界 |
|---|---|---|
| 产品停用 / 暂不供样 | 两项独立状态，不能互相代替 | 后端权限与扫码过滤仍需验证 |
| 色卡资料变更 | 显示需重新打印，运营逐卡确认 | 旧确认不能清除新修订号待印 |
| 色卡删除重建 | 旧卡已失效，同组合新卡为新身份 | 旧码永久作废，不恢复旧链接 |
| 选样资料 v1.50 | 读取最新主数据，保留选择事实；正常无有效标识 | 旧快照后端尚未全改，需按切片验收 |
| 已保存三种单据 | 保存属性口径和历史手工明细保护 | 不能套用选样实时刷新的规则 |
| 管理权限缺失 | 只读/无权反馈与实际角色一致 | 前端隐藏操作不替代服务端检查 |

管理员、业务员及独立授权按现行需求逐项映射，不能从“业务员”角色直接推断具有所有管理权限。新建/更换单据明细的管理员手工例外不扩大给业务员。客户公开花型分享与登录业务员扫实体色卡选样是两个入口，不混用公开范围。
