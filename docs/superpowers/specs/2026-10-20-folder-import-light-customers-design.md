# 文件夹导入与轻量客户档案：本轮交付设计

状态：用户于北京时间2026-10-20 16:55要求“导入花型库要支持选择文件夹和多个文件；轻量客户档案这次实现，更新需求”。用户17:08已确认并要求一次完成；本地实现、接线、专项复查已完成，见[实现记录](../../product-master/README.md)，未执行真实迁移或上线。客户模块沿用[已有客户档案工程设计](2026-10-20-customer-profile-retention-design.md)，以下明确本轮范围和必要交互。

## 目标和范围

在现有花型导入中直接选择一批文件或整个目录；客户来选样时，建立可重复使用的轻量档案，后续能查询选样/寄样/跟进、识别重点客户和处理到期联系事项。两项独立实现和验证，保留上一轮本地色卡分享及导入修复，不混写为已发布。

客户只在选样单上追加字段会反复填报且难汇总；独立轻量档案可以复用现有业务；完整CRM需要额外商机与财务体系。本轮采用已讨论的第二种方案，不引入完整CRM。

## 花型导入交互

- 弹窗保留“选择多个文件”，新增“选择文件夹”。前者允许一次多选；后者使用浏览器目录选择，包含子目录图片。两者共用当前校验、预览、进度和逐张保存流程。
- 文件名取最终文件名，如`春夏/花卉/G0008-1.jpg`仍识别为`G0008-1`；目录名不推断母版号、标签或配色。不把本地绝对路径上传服务器。
- 一次新选择替换当前待导批次，取消文件选择保留当前批次；已开始导入时禁用两种选择。导入后明确结果，选择新批次才可再次导入，避免自动重提不确定写入。
- 不同子目录出现同一母版＋配色号时，全部列为重复冲突，用户处理后重新选择；不得静默挑选其中一张。非图片、空文件、格式/命名/20MB限制逐项反馈。仍按母版与数字配色升序处理，失败暂停同母版后续，其余母版继续。
- 浏览器不支持目录选择时显示说明，多个文件入口继续可用；不能声称一次原生目录选择支持多个目录。

## 轻量客户页面和选样流程

- 内部导航增加客户档案页，按名称/联系人/品牌搜索，可按渠道、等级、阶段、归档筛选。管理员可看全部，业务员仅本人和明确授权客户；列表、候选、计数、详情、历史与待办使用相同范围。
- 快速建档仅要求客户名称及电话/微信至少一种。主体类型可待补充，其余资料均可后补。完整编辑支持公司/个人、主要开票抬头、多品牌、联系人、电话/微信、地区、线上/线下/兼有/待补充，以及按面料类别分开的价格区间、币种、米/码单位、含税口径。未知留空，价格按定点小数存取，不补零、不自动换算。
- 新建选样可搜索选择已有客户，或快速建档并建选样。快速建档和建选样同事务、幂等请求，取消不写入、失败整体回滚；已有客户多次选样关联同一档案。保存中防重复提交，失败保留草稿。
- 客户详情显示资料、负责人/协作人、选样/寄样与跟进时间线、待办；直接复用现有选样产品、寄样批次和跟进事实，不复制业务历史。
- 支持客户级联系记录及下次跟进任务。今日/逾期按上海日期计算，任务可完成/取消并保留历史；寄样待反馈可查。旧跟进中的下次日期仅展示，不能自动把每条旧日期都当逾期。
- 等级A/B/C/未评级与潜力/选样/成交/复购等阶段独立，人工调整填写理由。价格预算不自动决定等级；订单未显式关联客户前不展示成交额、利润和复购率。

## 数据、权限和兼容

沿用已有设计的客户/联系人/品牌/价格偏好/协作授权/变更事件、客户跟进及待办模型，选样单追加可空客户ID和关联版本。旧客户名称、扫码来源、寄样和跟进原样保留；旧单须人工核对后关联，不能按同名自动合并。档案可归档，不物理删除历史；归档后不允许新建关联业务，既有历史可读。

每次内部请求复核有效账号和会话。客户负责人和edit协作可维护，view协作只读；负责人/管理员管理协作，仅管理员转移负责人。已关联选样的所有目录、详情、图片、扫码、人工加入、移除、状态变更、寄样和跟进入口均受当前客户权限约束，旧session_access不能绕过客户撤权。未关联旧单沿用原权限；客户权限不扩大三种单据owner权限。无权ID返回404，不通过重复提示泄露他人资料。

写操作按统一顺序锁账号/会话、客户/授权、选样与业务行；版本冲突409并保留草稿。旧单关联同时验证旧单管理权和客户edit；客户新建与关联记录均保留必要审计。幂等键绑定操作者与规范化请求，复用键携带不同内容应拒绝。

新增数据库结构用独立受控加法迁移，准确数据库/服务器身份、备份摘要、迁移锁与账本、重复执行及schema合同分别验证。正常启动只读检查；新结构未准备好时客户功能明确不可用，既有未关联业务继续可用。迁移不自动匹配历史客户，不删除旧数据。生产迁移和部署不在本轮开发中自动执行。
