# 色卡级花型产品分享设计

状态：用户已确认设计、实施计划并选择“直接实现”。本地实现、一次独立审查修复及全量检查完成；生产迁移、发布和浏览器/实体微信验收未执行。详见[实现验收记录](../../product-master/product-master-v2-card-sharing-20261020.md)。

## 目标与选择

客户收到一张色卡的分享链接后，可以看到该色卡对应的全部配色产品及各自的面料大图、细节图、效果图，便于一次比较。分享入口放在色卡库操作中，产品库移除该入口。

当前已有产品分享签发、稳定链接、客户只读页面、图片白名单和大图能力；色卡本身已按母版ID＋面料ID唯一绑定。方案复用这些流程，新增加色卡级发布映射；不复用内部扫码令牌、不将单品旧链接静默扩大为整卡展示。

仅把按钮移到色卡后继续签发一个产品链接仍只能看单品；复用整个母版旧链接会把其他面料一起分享；因此选择独立色卡链接并按该卡范围动态读取。

## 界面与客户展示

- 色卡列表操作增加“分享花型产品”，与“查看花型”“查看二维码”“删除色卡”并列。点击打开稳定链接窗口，支持复制和预览。停用/删除卡不能新签发，现场复核失败明确提示。
- 产品库移除“分享花型产品”操作；既有查看图片、编辑、关联色卡和建卡入口保留。
- 客户免登录。页头显示色卡编号、面料品号/品名、成分、克重、门幅；不展示价格、成本、内部备注、客户资料或内部扫码信息。
- 按数字配色顺序分区，显示完整产品货号，每个配色分别展示面料大图、细节图、效果图及数量，可点开大图。缺图明确显示“暂无图片”，不借用兄弟配色或其他面料图片；图片延迟加载，不能只显示第一配色而隐藏其余。
- 范围是同一母版ID **并且** 同一面料ID已建立的产品。只展示产品、配色、母版和面料当前均启用的记录；没有建成产品的配色不拼造图片。供样开关控制内部选样，公开展示仍沿用产品启停口径，不将“暂不供样”自动等同公开下架。
- 后续新增同母版、同面料有效配色产品，原链接自动纳入；更换为其他面料则属于另一张色卡，不混入本链接。零个可展示产品显示“暂不可用/暂无可展示产品”。

## 稳定身份与权限

新增card_share_links：id、card_id、token_hash、status(active/inactive/revoked)、revoked_at、created_at；card_id唯一、token_hash唯一，外键关联同库sample_cards.id。卡ID使用字符串传输，公开响应不返回数据库ID、原始图片地址或令牌摘要。

公开token使用既有32字节服务端密钥和独立命名空间按card_id稳定派生，只在有效内部账号明确点击分享后保存发布记录。新链接形如/c/:token，与旧/p/及/s/隔离，不使用qr_payload或sample_card_tokens。稳定派生和唯一约束保证重复点击/并发生成复用同一链接；已撤销发布不自动复活。

管理员和业务员沿用现有分享权限，每次签发现场复核账号、会话和卡/父记录当前状态；账号与会话锁先于母版、面料、卡和分享记录，兼容现有删卡锁序。客户端不能提交母版/面料/产品名单来扩大范围。

公开JSON与每次图片读取都验证：已签发且有效的色卡分享记录、卡未删除且启用、母版和面料启用，以及产品和当前图片映射仍在该卡范围。图片内容读取后再次检查失效/范围，沿用no-store及无referrer策略。

| 变化 | 原色卡分享链接行为 |
|---|---|
| 同范围新增配色产品或图片 | 动态更新展示 |
| 某产品/配色停用 | 隐藏该配色产品，不影响其他有效产品 |
| 色卡/母版/面料停用 | 整卡暂不可用；恢复启用后原链接可恢复 |
| 色卡删除 | 原链接永久不可用，不能靠同编号新卡复活 |
| 同组合重建色卡 | 新卡ID、新分享链接，旧链接保持不可用 |
| 旧单品链接/s/:token | 保持原来单品范围，继续原有权限和图片校验 |
| 旧母版链接/p/:token | 保持原有范围，不重定向为色卡链接 |

## 接口与实现边界

- POST /api/v2/sample-cards/:cardId/share，空JSON；201首次签发、200复用；不接受scope覆盖参数。
- GET /api/public/cards/:token，返回色卡公开摘要及按配色组织的产品三类图片白名单。
- GET /api/public/cards/:token/images/:ref，只读派生展示图，复用现有图片放大组件。
- GET /c/:token复用公开展示应用入口。能力接口新增cardsEnabled，独立于既有productsEnabled；数据表未准备好时只关闭新色卡分享，不破坏旧链接及其他业务。
- 目录加载器增加可信服务端的fabricId范围：产品和图片SQL都限定母版＋面料，排除无对应产品的配色，不带花型设计原图；旧单品及母版调用保持原行为。
- 代码主要落在server/customer-share/、公开展示组件、SampleCardTable/SampleCardLibraryV2、V2App/能力读取，以及静态公开路由；不扩展客户档案或选样权限。

## 数据迁移与发布

加法新增发布映射表，不修改既有产品、色卡、图片和分享记录。沿用现有operator-only迁移模式：精确目标数据库/UUID、备份摘要、单条物理连接持迁移锁、迁移账本和只读schema合同；正常启动只验不建表。旧表不复用为不同含义。

本轮先开发并在隔离数据验证，生成可审查的迁移及程序产物。真实迁移与生产发布作为后续操作处理，不因设计或本地测试通过自动上线。回退程序不删除新表/发布记录，保留旧链接数据。

## 验收清单

1. 产品库无新分享入口；色卡库可以复制/预览；重复及并发签发稳定，内部QR不泄露、不改变。
2. 同母版同面料两配色、另一面料和另一母版同时存在时，仅包含本卡两配色；每个配色三类图片不串图、无图留空，货号及规格正确。
3. 不能猜测产品/图片ID或改变查询参数访问其他卡、面料、原图、价格或内部字段；签发需当前有效管理员/业务员，公开读取不要求登录。
4. 图片读取中撤销/删卡/改关联，内容不返回；停用与恢复、删卡后同组合新卡、零产品、新增配色均符合上表。
5. 旧/s/和/p/链接保留原范围与现有回归；新表缺失只禁用新功能，不影响旧功能启动。
6. 页面完整展示多配色，移动端可切换/滚动及查看三类图片大图，关闭返回原位置；不把模拟数据验证算成实体微信/正式浏览器签收。
7. 新表元数据的类型、唯一索引、同库外键和目标身份通过验证；迁移幂等/锁失败不污染连接池，运行时不执行DDL。

## 设计确认与后续

本设计采用“全部当前启用产品、缺图保留占位、旧单品链接不扩容、公开链接独立于内部扫码”的默认口径。唯一需求已修订为v1.52，新增AC-110～115；用户已确认实施计划并选择直接执行。规划时652文件清单保留为历史，最终清单独立冻结，之前导入修复和正式发布证据保持。
