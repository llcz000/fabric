# 客户档案 UI 优化计划

范围：现有 CUSTOMER-01～08；内部工作台效率优化，沿用活动工作区及客户业务模型。用户已授权本轮优化，部署另行授权。

设计：保留列表与详情两层入口。相比增加抽屉或把客户全做卡片，收紧现有表格和表单能保留熟悉的流程、减少回归。基础资料/联系人与偏好/回访在桌面并排，360px单列；紧凑的品牌、联系人和价格行保留全部字段；主操作清晰、保存容易触达；精简返回/刷新/移除文案且保留可访问名称。

执行裁定：用户追加选样删除统计错误，纳入同主题修复；不做部署。已完成当前范围的本地验证，宽范围tsc的既有阻断另记。


## 用户二轮修订（2026-10-23）

已授权：品牌并入基础资料，单品牌输入；收紧所有字段；列表常驻详情/编辑/删除（服从权限）；不再提供刷新档案。方案采用保留列表的原生dialog，详情以文本显示并提供资料/业务历史Tab，编辑/新建直接表单且不带Tab；删除直接确认。相比整页来回切换可保留筛选/分页和焦点，相比多层编辑Tab减少操作。所有读取沿用现有API，关闭不刷新，保存/删除后自动重查列表。

- [x] 改正式组件、紧凑字段与只读详情；删除/脏态/权限/焦点/异步保护。
- [x] 实际桌面与360px主窗口/所有弹窗截图及浏览器、定向类型/测试/构建；同步需求的客户UI小节。
- [x] 更新同主题报告、候选源码与门禁；记录用户接受pending、未发布和历史保留。


## 用户三轮修订：减少字段并避免桌面滚动

已授权：开票抬头不再编辑/展示；价格仅面料类别、范围、备注，新填写固定人民币/米，不提供币种、单位、税口径选择。原开票/价格旧属性保留于数据模型，无无关编辑丢失或生产迁移。普通编辑布局改为基础/联系人、偏好/回访、价格三行，实测1366×768及1440×900，默认常用面料只显示已选资料；查找候选按输入显示。单次默认数据完整展示，额外多行及窄屏保留安全滚动，不能剪裁字段冒充完整显示。
