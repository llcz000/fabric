| 触发/根因 | 可复用处理 | 适用边界 |
|---|---|---|
| DELETE因FROM子串被误认SELECT；JOIN与普通词表读混淆；常量UPDATE绑定参数模拟错误 | 匹配SQL动词、联接语义和真实绑定参数，拒绝未预期SQL；先查替身行为，再判断业务缺陷 | 不能据模拟锁序推断InnoDB无死锁 |
| LIMIT/OFFSET颠倒、缺ER_DUP_ENTRY导致错误空页或重名“成功” | 夹具模拟数据库分页/唯一分支；保留DB UNIQUE/FK作为最终防并发保护，不加事务外查重掩盖竞态 | DECIMAL精度/可空值与并发需目标库验证 |
| 2,100条记录缺默认状态/row_version或关键词只匹配99母版 | 先明确期望数据集合；B0匹配B001～B099得2079、B匹配全部得2100；修夹具或预期，不擅改正确SQL | COUNT与分页必须同WHERE；模拟耗时不能报网络P95 |
| 单独图片服务通过但列表出现N+1/账本次序失配 | 按页批量读取图关系；字段/关联/引用数同事务，断言共享2→1→0与整笔回滚 | 真对象存储、真实时间回收和订单桥另验 |
| 标签归档/合并与并发新增关联冲突 | 锁对象后锁标签，唯一键兜底，归档已有关联可追溯但禁新挂，合并去重且失败全回滚 | 同维规范化、管理员权限和谁何时治理的审计分开 |
| 真库测试可能碰到已有数据 | 固定隔离库、表白名单、逐表空行、每写连接核SELECT DATABASE()，仅清当次夹具再核归零 | 不依据测试名字判断安全，不操作生产库 |
