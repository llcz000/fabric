# 早期安全与业务正确性治理复盘

> 文档定位：复盘经验｜主要读者：开发、测试/评审、Agent。用途：遇到同类问题时读根因、做法和验证范围。

状态：历史经验。由旧知识库实施清单、早期架构审计提炼；原记录时间 2026-08-13。本轮核对相关代码入口，不重复宣称当时测试结果代表现在或线上。

## 问题与处理经验

| 原问题 | 已记录处理 / 后续应沿用的方法 |
|---|---|
| 默认密码、会话与登录攻击面 | 缺少 ADMIN_PASSWORD 拒绝启动；token 过期/退出撤销；登录失败与 API 分层限流 |
| 图片代理 SSRF 与上传伪装 | HTTPS/地址和重定向逐跳校验；图片真实解码、格式一致、大小/像素限制；Excel 真实解析 |
| 前端先删、服务端后失败 | 删除或保存先确认服务端成功，再更新界面与缓存；批量删除用精确 ID |
| 上传临时文件遗留 | 校验失败、业务失败及成功转入 COS 后清理临时文件；保留仍被业务引用的本地文件 |
| 假降级/演示数据污染 | API 失败展示本地快照状态，不创建或持久化演示订单冒充服务端数据 |
| 跨产品图片/路径越界 | 同时校验产品归属与图片 ID，本地路径限制在 uploads 根目录 |
| 进程在线不能说明存储正确 | 健康检查公开实际存储模式，并结合关键 API 验证；SIGTERM/SIGINT 优雅停机 |

## 当前源文件证据

server.ts：ADMIN_PASSWORD 必需、token TTL、退出、限流、代理/上传验证、健康与存储选择；src/lib/externalImageUrl.ts：外部图片 URL 边界；scripts/smoke-security.mjs：生产安全冒烟。

“无法公网发布”“没有测试”“凭证已轮换/仍未轮换”“某次构建通过”都是特定时间的判断。现在是否满足部署条件要现场验证；本轮没有检查云端凭证轮换、实际 HTTPS 或业务数据。
