# 经验速查（已从日期复盘中提炼）

> 旧复盘原文不再作为日常推荐入口；旧工作区副本待安全归档移除。以下原则结合当前源码和现行需求使用；旧实现细节、测试次数不代表现在有效。

| 遇到的问题 | 复用经验 / 当前规则 |
|---|---|
| 产品自动建卡、共享图片修改或切换期漏卡 | 先锁母版/面料/组内全部配色再碰产品图片；同事务建卡/退役并保留历史码；补卡账本可重跑补缺，新后端健康后再补一次，真MySQL并发验收独立登记 |
| 旧测试在规则精简或查询字段增加后失败 | 先复现并对照唯一需求；停用请求应拒绝且不写入，SQLite替身补齐投影列，HTTP删除替身覆盖审计/退役/回滚；保留引用与永久身份断言，不放宽生产代码来迁就旧用例 |
| 删除产品、配色、色卡后引用异常 | 先校验产品/单据/历史色卡和共享图实际引用；按服务端事务处理，失败不部分提交或销毁被引用的资产 |
| 上传大批花型失败、图片替换、同名编号复用 | 校验真实格式/大小/像素/并发，单图失败不阻断其它结果；图片替换保持有效关联和来源可追溯 |
| xlsx 导入与预览不一致 | 复用后端校验和模板；行级错误隔离，真实MySQL并发/FK单独验证；不要为旧WPS/ZIP导入扩需求 |
| 单据汇总或打印/PNG/Excel不一致 | 复用统一计算与打印模型；扣损、定金、逐匹和长文本在桌面/窄屏/纸面共同核验 |
| UI门禁提示候选与历史评审范围不符 | 先比较真实UI、候选源码清单和已发布清单三方身份；先精确登记已审需求/源码，再生成新候选评审，不能改旧报告凑范围。门禁需先拒绝遗漏的新UI及变更/删除；确无UI差异应明确无需新审。37项回归验证，旧证据保留，归档不适用 |
| 手机扫码全选与部分配色操作互相覆盖 | 首扫可全选，重扫只追加新产品；主动取消保留为选择事实，恢复必须显式操作。失败重试复用幂等移除/恢复，不因响应丢失反向切换；键盘焦点不能因保存中临时禁用按钮而丢失。已用200项定向回归及12项浏览器场景验证，微信真机另验 |
| 私有页面将404一律当成对象已删除 | 会话授权可能通过404隐藏身份；先清空可见私有数据，再独立核验会话，无法确认则撤销本页访问。搜索失败后同词重提也必须重新请求，不能只依赖搜索词变化。浏览器撤权及同词重试场景已验证 |
| 多选/弹窗取消丢内容、界面卡顿 | 使用稳定ID、保留未保存草稿，Esc/关闭/取消不误提交，长列表按需加载并验证大批量 |
| 登录、图片、客户公开页越权 | 服务端所有入口核验身份/归属和公开白名单，未授权响应不泄漏客户、价格、内部链接或服务器路径 |
| 部署成功但业务不可用 | 用冻结SHA验证实际运行模式、数据库目标、关键授权HTTP和公网资源；必须有备份/失败回退 |
| 同时运行测试触发临时目录冲突 | 使用隔离临时输出，等待进程退出；测试、lint、构建按影响串行验证，不把环境异常误判为业务失败 |
| 多Agent错用陈旧文件 | 固定唯一 `D:/fabric` 主仓库，任务独立工作树，Git/SHA256所有权检查，独立审查后合并退役 |

正式安全/测试门槛见[开发与验证规范](../development/开发与验证规范.md)，正式设计见[项目设计](../project/项目设计.md)。旧排查过程可按[外部备份清单](../maintenance/文档整合与恢复.md)恢复；不自动恢复旧业务决策。


### 客户选择与选样导出

- 搜索列表以规范化关键词驱动时，不能在仅空格变化的输入事件中先清空结果，否则关键词未变、请求不会重跑，已有客户会消失并诱导重复建档；用真实浏览器覆盖末尾空格与错误重试。
- 将新建入口改为条件渲染子页面时，要逐条检查能力开关分支的离页保护；主分支子组件注册了保护，不代表兼容分支也有，延迟提交期间必须阻止离开。
- 为目录新增关联计数，要同步测试数据库中的关联表和时间函数适配；用实际SQL执行验证去重、已移除项和跨单隔离，不以固定计数替身代替。
- 按单Excel导出从服务端当前授权及选样来源推导范围，复用已有Workbook格式；不能信任客户端勾选ID，也不能复用列表单页作为完整导出集。

- 选样状态与入口调整后，SQL替身必须匹配当前锁查询，真实HTTP测试不得因替身漏读而把503当业务拒绝；重扫保留主动取消，恢复走明确补选，固定签字栏不再断言旧配置文案。全量检查应先排除生成制品，不能只给定向结果。已有经验保留，当前状态与发布回执以项目现状为准，无文档归档/清理。
- 发布前浏览器回归会重写通用截图路径；截图须等待能力/加载态就绪，审查时再复制到候选专属路径并核对SHA，冻结包只引用该路径，不能让后续测试覆盖已审证据。

- 影响分析必须覆盖内部选样组件、tests/ui与预览夹具，专属功能归属优先于宽泛目录；测试AC注释只提供可查场景，不冒充执行证据。长期脏工作树使用已核验清单比较本轮输入，未知路径和需求漂移不能静默忽略。重测先消除同轮重复执行，不缩小1000次导入断言；截图封存先校验再快照，浏览器临时目录先等子进程退出再按工作区/前缀边界回收。
