## 可计算知识全图与改动影响

直接查询支持 `tests/ui/` 和 `tools/`；测试文件用单行 `// AC-164` 或 `// AC-163, AC-164` 标注场景归属，查询优先展示这些直接场景，仍不代表测试已执行。针对长期未提交工作，可运行 `node scripts/fabric-knowledge-graph.mjs changed --from-manifest artifacts/releases/已核验版本/package/source-manifest.json` 比较本轮源码/测试与固定输入；需求摘要变化仍保守扩大，未映射路径单列人工核对，不替代文档审查或发布源门禁。

当前唯一需求ID、文档入口、验收用例、11个业务域、代码/测试候选之间的关系通过 [知识治理规则](maintenance/知识维护规则.md) 和 `scripts/fabric-knowledge-registry.json` 维护，不再另写一份静态大图。它按需扫描真实文件、Markdown链接及需求编号，避免新副本过时。

在 `D:/fabric` 运行 `npm run knowledge:map` 查看全域结构，`node scripts/fabric-knowledge-graph.mjs map --mermaid` 生成可视化概览，`node scripts/fabric-knowledge-graph.mjs map --json` 获取全部节点与关联；需求或验收修改前运行 `npm run knowledge:impact -- CUSTOMER-07` 或 `npm run knowledge:impact -- AC-105`，改动后运行 `npm run knowledge:changed`，完成前运行 `npm run knowledge:check`。**映射只给出影响候选，最终代码依赖与测试必须实际验证。**
