## 现在是什么

- **正式应用版本：V2-only。** 当前 `server.ts` 无 legacy/JSON 回退启动路径；`src/App.tsx` 只加载内部 `V2App` 和受限的客户公开分享页。旧文档中的“V2 未挂载”“线上仍是旧 App”“候选未切流”是历史事实，不再作为当前开发结论。
- **唯一开发目录：** `D:/fabric`。曾经的控制目录 + 内嵌应用工作树已合并；常规开发不应再进入 `.agent-workspaces/v2-quality-20261020`。
- **最近有据可查的发布：** `20261023t095703554-2938438a`；历史回执 `artifacts/releases/20261023t095703554-2938438a/release-result.json`。该发布包含产品批量选品上限崩溃修复，回执记录该修复已发布并验证；不代表其他功能已验收，也不代表本轮重新完成生产检查。
- **小规模业务精简已获批准：** 取消常规启停/供样维护、复杂删除留痕、寄样跟进和协作归档；客户档案、回访、三类单据历史和色卡公开分享按现行要求执行。以需求总览 LITE/CUSTOMER 条款及源码实际实现为准。

## 不应假定已完成的验证

当前源码存在不代表以下项目在**本次整合**中重测：真实多用户跨权限、目标 MySQL 迁移与回滚、COS 原件/引用回收、长列表大批量图片上传、微信真机扫码/分享、纸质打印、全部 UI 人工审美验收、库存新逻辑。遇到需求/缺陷时按本次范围补证据，不自动扩张为全量开发。

**库存**仍按用户批准的后续范围处理；不得凭旧路线图自动进入当前阶段。当前小团队不恢复旧寄样、独立复杂 CRM 流程和取消的授权开关。

## 开发和发布状态

本轮仅整理知识文档，未修改应用逻辑，未执行生产部署。软件版本、测试与上线证据的详细历史归于仓库外 SHA256 文档归档；不能用旧日“待发布”“已通过”文本覆盖当前事实。使用 `npm run parallel -- audit` 判断工作树状态，`npm run v2:source` 校验可信源码，`npm run ui:preflight` 校验 UI 规范，`npm run test:release` 验证发布工具（不等于生产发布）。

若有新需求或缺陷，**只更新对应项目需求和本页的一条状态**，避免再写一篇发布日期的过程记录。
