## 技术与验证

React19、TypeScript、Vite6、Tailwind4；Express4、Zod、Multer、Sharp、MySQL、腾讯云COS、ExcelJS及html2canvas-pro。版本以package文件为准。

MySQL为业务主路径，服务端JSON与浏览器IndexedDB/localStorage兼容路径仍在；图片新旧链路共存，不能描述为全面迁移完成。package.json已有lint/build/单元/安全及图片冒烟命令，存在脚本不等于本轮通过。

本仓库审查分支另有远端 GitHub Actions 构建（Ubuntu/Node24）及审查版安全治理：COS SDK 3.0.0 的伪凭据只读签名兼容冒烟通过，未使用的 Transformers 依赖链已移除，审查锁文件当前生产依赖只读审计为 2 项（0 严重/0 高危/2 中危，仍有 ExcelJS→uuid 关联待处理；先前基线为16项）；这些是审查分支检查，不证明当前正式 App / 线上主机已升级。发布 P1–P7 仍 No-Go，详见[远端审查构建与上线门禁](../operations/fabric-v2-remote-build-and-deploy-gates.md)。

V2状态与历史验收只在[当前进度](../product-master/product-master-v2-progress.md)维护；本页不重复测试数量。未完成的正式接线、存量schema迁移、真实MySQL并发/COS、手机扫码、用户视觉与部署分别收口。
