## 1. 业务场景与流程

### 1.1 准备公司与产品资料

1. 管理员和业务员维护统一开单设置，包括公司、收款码等展示资料；修改后，新单和全部已开单据的展示、打印及重新导出都使用最新设置。
2. 两种角色均可维护产品资料及图片，团队共用同一份资料。
3. 产品资料只由花型库、面料库和产品库管理；具体配色与面料组成产品，满足启用条件后用于新业务。

### 1.2 给客户开单并交付

1. 管理员或业务员按业务选择样布码单、销售发货码单或定金单，填写客户、日期和明细，并引用统一开单设置。默认选择库内产品，仅管理员可主动使用手工录入模式。
2. 按单据类型自动计算总计米数、总匹数、合计金额与应收金额；销售发货单另算扣损合计并手工填写定金金额，定金单按手工填写的百分比算出定金金额。校验后保存，失败时提示并允许继续编辑，不能显示保存成功。
3. 保存成功后预览，按需输出 PNG、打印 Excel 或 JSON。后续修改更新原单；复制则形成新单，不覆盖原单。保存时冻结的产品资料不随后续修改追写旧单。
4. 销售发货单的应收金额为合计金额减定金金额；定金单不设应收金额，列表与大盘不汇总定金金额。

### 1.3 查找历史业务和经营情况

1. 用户按客户、产品、日期、类型和结清状态查找自己有权查看的单据。
2. 展开命中明细、查看合计，按权限查看、修改、复制或删除单据。
3. 通过大盘查看分类数量、米数、金额、品名排名与最近单据；管理员看全公司，业务员只看自己开的单。查询、输出和统计始终遵守同一数据范围，不能借报表查看他人单据。

### 1.4 管理入库与库存

库存功能不在当前实现范围，以下为已确定的口径，待排期实施。

1. 管理员或业务员按入库日期、品名录入匹数、米数和备注，形成入库记录。
2. 样布及销售单据形成出库，定金单不出库。台账按入库减出库计算结余，支持按品名查询。
3. 出库匹数按销售行内已填分匹的条数计，不按明细行数计。单据保存时扣减库存，删除或改单时按差额冲销。
4. 删除入库记录须确认并重新反映台账结果。

### 1.5 为客户选样并反馈

1. 登录的管理员或业务员进入客户选样单，扫码或搜索有效色卡；补选列表首列色卡编号，一行一卡，展开默认选中全部有效配色，也可取消部分勾选。支持整卡或勾选加入；未建卡产品不可选，跨面料先建立对应色卡。
2. 检查当前色卡、产品、资料存在性及卡内归属；未选则添加，已选提示重复，已移除项可恢复。零勾选禁写；无权或选样单关闭拒绝添加；整卡/子集写入失败回滚，人工选择保留来源而不伪造扫码。
3. 添加后刷新结果并读取最新资料，移除保留必要历史。业务历史只记录选样、反馈和三种成交单据；客户维系只保留下次回访提醒，不维护寄样流程。公开色卡分享与内部扫码权限独立。

### 1.6 团队协作与账号

1. 管理员新增系统账号，业务员不能新增账号；用户使用系统登记的账号登录，账号停用或删除后原会话立即失效。
2. 业务员查看、编辑自己开的单；管理员可查看、修改和删除全部单据，修改或删除他人单据时保留原开单人记录。手工录单只对管理员开放。
3. 两种角色均可导入面料和导出资料，重复记录显示差异，由当前导入人二次确认处理方式后执行。

### 2.1 登录、角色与权限（BASE-01、INC-01）

| 编号 | 事项 | 管理员 | 业务员 |
|---|---|---|---|
| AUTH-01 | 新增账号 | 可以 | 不可以 |
| AUTH-02 | 单据范围 | 可以查看、修改和删除全部单据 | 只能查看、编辑自己开的单 |
| AUTH-03 | 开单手工录入 | 可以主动切换手工模式 | 不可以，必须选择库内产品 |

| 编号 | 要求 |
|---|---|
| AUTH-04 | 只接受系统登记账号登录；会话失效、账号停用或删除后不得继续访问或写入内部业务数据；登录、鉴权和数据归属由服务端逐次校验。管理员提供有权限范围内的可见密码重置入口，不泄露或直接展示已有密码 |

### 2.3.1 小规模业务规则

当前按小团队单人开单设计，不建设临时停售、审批、作废、回收站、恢复或独立删除日志管理页面；删除的最小审计事件仍按 LITE-03 执行。开发与上线状态另见[项目现状](项目现状.md)。

| 编号 | 当前唯一规则 |
|---|---|
| LITE-01 | 花型母版、配色、面料、产品不再人工维护启用/停用；移除状态字段控件、状态列和包含停用筛选。产品取消“暂不可选样”，单个和批量新建均默认可选样/开单，图片可后补；正常未删除资料默认可用于新选样、开单和色卡分享。账号启停、登录权限及删除有效性保护不变。 |
| LITE-02 | 兼容旧数据库字段，不直接删列；通过显式、备份保护且可重复执行的登记迁移盘点并统一未删除资料为可用。不得恢复已删除母版/面料/色卡，不得恢复撤销的旧色卡码；迁移不在应用启动时执行。新API不得再写入停用或不可选样状态。 |
| LITE-03 | 花型、面料、产品、色卡、客户、客户选样、单据删除自动记录最小事件：对象类型、内部ID、编号/名称、操作人、时间。不保存单据全文/明细快照，不填原因，不加审批；记录和删除在同一事务，记录失败不允许假报删除成功。权限与明确的一次确认沿用。 |
| LITE-04 | 单据直接删除主表、明细及客户关联，成交统计随删除更新；不增加作废状态，不保留原单内容，不提供恢复。历史管理员跨账号操作审计仍可保留，但所有删除均需最小事件，不能只记录管理员删除他人单据。 |
| LITE-05 | 删除客户、色卡、选样时移出正常列表/新增选择，保留原有历史保护；客户删除不连带删除单据。花型/面料有产品引用时仍禁止删除；产品被已保存单据引用仍禁止删除，提示关联保护而不再提示改为停用。共享图片引用与旧记录不被误删。 |
| LITE-06 | 色卡只提供复制固定链接/查看分享，重复分享复用地址；不新增人工撤回、期限、密码或发布审核。删除色卡后旧分享和内部码自动失效，同组合重建不复活旧码。重点客户、待回访、关联色卡、需重新打印等实际业务标记保留。 |

| EX-05 | 同批次按母版和数字配色升序逐张反馈成功/失败；单张失败不阻塞后续，用户按结果清单重选，不自动重复提交不确定写入；重导同图不重复建配色或累计引用，较小编号不回退自动计数；不扩展ZIP |
| EX-06 | 面料Excel仅支持 `.xlsx`，不支持 `.xls`，直接展示七列模板示例，不做列设置；按表头自动识别，兼容《底布编号 -OK.xlsx》的数字品号、gsm/mm和门幅表头。面料品号仅做空校验，不限制字符格式；前后端、产品关联及数据库约束一致。重复品号保持原有跳过/确认更新规则，单位及规格规则不变 |

已批准的色卡 Excel 导出见 [2.10](#v2-selection) V2-13。

### 2.5 开单、明细与计算（BASE-02）

| 编号 | 要求 |
|---|---|
| DOC-01 | 三种单据支持创建、查看、编辑、保存、复制和确认删除；复制不覆盖原单，权限按 2.1 节 |
| DOC-02 | 单头含类型、编号、日期、客户、开单人和收货人；公司信息引用统一开单设置，签字栏固定，备注条款按本单保存。编辑页为基本信息/紧凑明细/实时汇总，签署与联系信息默认收起，不新增“款式号”；库内选品资料只读完整展示。定金单另含收货地址与联系电话；预览固定保留地址空白栏，填后按单据存储值在 PNG 与打印 Excel 展示 |
| DOC-03 | 默认编号由 YB/XS/DJ 前缀、日期和序号组成，可编辑；客户输入可参考已有客户名称 |
| DOC-04 | 新单类型按样布→销售发货→定金排序；支持增加、删除、清空明细，须有客户及至少一条有效明细才可保存，空白行不入单。数量、单价、扣损、定金金额/比例等适用的0默认显示空白，允许为空的值按0计算；输入未完成或小数无效时保留原文，标记具体行/字段且阻止保存，纠正后清除旧错误，前导0不误报 |
| DOC-05 | 样布行金额＝米数×单价；汇总总计米数、总匹数（明细行数）和合计金额，应收金额等于合计金额；不设定金和扣损；支持结清标记 |
| DOC-06 | 销售明细一行标识一个货号，行内按匹录入各匹米数，初始10个输入位、可追加；输入未完成或无效时不能作为清空保存，匹数与匹数上限不设硬限制、可按需增加输入位；匹数取已填分匹的条数，毛米数取各匹米数之和；行扣损米数按行填写，行金额＝max(0，毛米数−扣损)×单价；单头汇总总计米数、总匹数、合计金额与扣损合计，手工填写定金金额，应收金额＝合计金额−定金金额；支持结清标记 |
| DOC-07 | 定金单不设匹数、结清标记或应收金额；输入定金百分比，定金金额＝合计金额×定金百分比÷100，不把合同余额当应收，不将百分比当金额。库内选品后的品名单元格仅显示品名，成分/克重/门幅仍随产品资料保存；定金地址展示及输出按 DOC-02，合同金额与定金金额的预览/导出口径按 DOC-08 |
| DOC-08 | 金额保留两位小数；每行金额先四舍五入到两位小数，再相加得到合计金额；定金单按合计金额×定金百分比÷100 计算定金金额后四舍五入到两位小数；仅销售发货单的应收金额用合计金额减定金金额，定金单不设应收金额；开单设置取当前值，产品资料取本单保存值，客户/米数/价格取本单业务值；总计米数、总匹数、合计金额与应收金额按单据类型自动计算，不手工覆盖；保存、重读、预览和导出保持对应字段及计算一致 |
| DOC-09 | 定金统一以金额表示，定金百分比仅作为定金单的计算输入；列表与大盘不汇总定金金额 |

**单头汇总字段**

| 字段 | 样布码单 | 销售发货码单 | 定金单 |

| 总计米数 | 明细米数之和 | 明细毛米数之和 | 明细米数之和 |
| 总匹数 | 明细行数 | 各行已填分匹的条数之和 | 不设 |
| 合计金额 | 明细金额之和 | 明细金额之和 | 明细金额之和，即合同金额 |
| 定金金额 | 不设 | 手工填写金额 | 由定金百分比算出，不手工填写 |
| 应收金额 | 等于合计金额 | 合计金额−定金金额 | 不设 |
| 扣损合计 | 不设 | 各行扣损米数之和 | 不设 |
