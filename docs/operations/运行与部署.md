# Fabric 运行与部署

> **现行运维入口**。实际发布命令统一使用[统一发布工具](统一发布工具.md)；过时的按日期脚本和旧控制器双目录不再适用。发布必须有用户明确授权，本文件不授予部署权限。

## 本地

从单根 `D:/fabric` 安装依赖并运行 `npm run dev`。实际生产/测试凭据在本机受保护配置和 `.env` 中，不能写入知识库。构建运行 `npm run lint`、`npm run build`，按需要运行 `npm run test:unit`、`npm run test:security` 或 UI 专项。当前 `server.ts` 只接受 V2 生产目标，配置不成立会拒绝启动，不再回退旧JSON/legacy应用。

## 发布工具固定流程

先运行 `npm run release -- plan` 了解阶段；本地离线工具验证为 `npm run test:release`。业务源码修改后，受控查看并批准源码集合的工具是 `node scripts/release/source-automation.mjs inspect` / `accept <精确文件>`，不能自动批准整个工作区。只有得到当前用户授权、目标数据库/服务器身份明确且备份可恢复，才能按冻结制品和发布计划执行发布。未知远端阶段结果只用原版本 `status` 核对，不自动重复重部署/迁移。

发布阶段必须验证：确切源SHA与生产旧版、目标MySQL身份/列约束、不可变制品、加密异地备份、必要的恢复演练、远端切换、`/api/health`/业务状态/鉴权、公网可信TLS及失败回滚。HTTP 200 或PM2在线不能单独视为成功。实际结果以 `artifacts/releases/<ID>/release-result.json` 等可验证原始证据为准。

## 数据与环境保护

客户/图片/导入源文件、`uploads/`、`template/`、`.env`、`.local/`、发布制品和旧生产备份绝不随知识库清理删除。MySQL主路径、图片COS、跨库FK/事务和真实浏览器/微信测试分别检查。图片资产迁移/回收详见[图片资产运维](image-asset-operations.md)。

最新系统状态参见[项目现状](../project/项目现状.md)，CI与上线审批参见[远端构建和发布Gate](fabric-v2-remote-build-and-deploy-gates.md)。

## 首次 V2 迁移留下的恢复约束

切流前必须冻结新备份、独立恢复并核验加密离机副本；停掉旧应用进程树及不识别 V2 图片引用的旧 worker。V2 已产生新写入后只切同版本 V2 只读恢复入口，不恢复旧可写 API，也不以旧 SQL 覆盖新数据。结构改变后的原值保护按原列逐值比较，不能跨结构只比较整表 CHECKSUM。旧启动自检曾产生订单汇总副作用，恢复旧进程前必须明确其写入行为。

历史生产、恢复库、回环性能、公网、浏览器与纸打/手机测试分别记录，不能互相替代；禁止向生产复制演练账号、客户、图片映射或性能夹具。10-19 具体包、备份、密钥恢复与审核原件在[恢复说明](../maintenance/文档整合与恢复.md#恢复位置)中成套定位；密钥及明文配置不入文档。未知执行结果或工具拦截先核状态，不换工具继续同一被拒动作。

## 交付检查与证据边界

单独的一期交付说明已合并到本节；唯一状态见项目现状，阶段源码入口见模块README，不维护第二份进度表。

`node scripts/check-fabric-v2-phase1-delivery.mjs --status` 只读核对正式入口的AST装配，不启动服务或连接数据库，不默认读取历史证据。未提供本次证据时八项验收可为pending、readyForReview:false，不能据此推断已经发布的应用未上线。

外部验收范围由检查器的 `PHASE1_EVIDENCE_GATES` 定义：目标MySQL迁移、备份恢复、角色/owner及旧接口、三库/COS、正式UI及用户接受、xlsx事务、三单据/历史输出、全链路安全/性能与回退。按本次变更和约定范围补证据，不因小修重复全部业务测试；本机/恢复库/公网/微信真机及纸质输出分别判定。

显式 `--evidence docs/operations/<本次证明>.json` 才加载 `fabric-v2-phase1-evidence-v1`。passed项须有reviewedBy、受约束Markdown proof路径和SHA-256 proofSha256；磁盘重读后拒绝缺失、空审核人、摘要失配、路径越界、符号链接及过大文件。历史签收按[恢复说明](../maintenance/文档整合与恢复.md#恢复位置)恢复原包，不改摘要冒充重新签收或新版本验收。

readyForReview:true仅表示指定资料齐备可评审，releaseAuthorized恒为false；发布/真实DB写入/切流/COS变更/旧库清退仍须各自明确授权，不由检查器授予或撤销。源码存在、HTTP通过、用户视觉接受和生产数据验收不能互相代替。
