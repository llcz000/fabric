# 实施清单

## 本轮已完成

### 安全

- [x] 删除默认管理员密码；缺少 `ADMIN_PASSWORD` 时拒绝启动。
- [x] 登录与 API 分级限流，token 设置 12 小时有效期并支持退出撤销。
- [x] 上传按路由限制为图片或 Excel，拒绝 SVG。
- [x] `/uploads` 要求登录 Cookie，并增加 `nosniff` 与 sandbox CSP。
- [x] 图片代理仅允许 HTTPS，阻断私网/保留地址并逐跳校验重定向。
- [x] 图片代理限制类型、10 MB 响应体和 10 秒超时。
- [x] 订单、库存批处理和公司配置增加明确的 schema 错误响应。

### 业务正确性

- [x] 单据、产品删除失败时不再先删除前端状态。
- [x] 公司配置只在服务端保存成功后更新界面缓存。
- [x] 产品批量删除优先使用精确数据库 ID，避免同货号误删。
- [x] 修复移动端销售扣损后的金额重算。
- [x] 修复定金 Excel 使用错误条款字段。
- [x] 图片上传脚本统一使用 `DB_*` 环境变量。

### 配置与清理

- [x] 合并 `.gitignore`，忽略缓存、临时文件、运行数据和敏感本地文件。
- [x] 统一 `.env.example`，只保留当前有效键和安全占位符。
- [x] 删除重复的 `gitignore` 与 `env.example`。
- [x] 更新 README、知识库安全基线和优化路线图。
- [x] 将跨平台清理命令写入 npm script。

### 验证

- [x] TypeScript 检查通过。
- [x] 生产构建通过。
- [x] 安全冒烟测试通过：认证、限流、输入校验、SSRF、上传类型、资源鉴权。
