# 术语表

| 术语 | 含义 |
|---|---|
| 单据（Order/Document） | 一次客户业务记录，包含抬头、客户、日期、明细和汇总。 |
| 样布码单 | 用于样布寄送的单据，明细强调成分、克重、门幅。 |
| 销售发货码单 | 用于大货发货，支持分匹米数、扣损、预收和结算。 |
| 定金单 | 记录订单金额与定金比例的单据。 |
| 单据明细（Order Item） | 一条面料产品和计量/价格记录。 |
| 分匹米数（pieceMeters） | 同一明细内每匹的米数数组；当前前端名称 `rollNo` 容易误导。 |
| 扣损米数 | 计价时从总米数中扣除的米数。 |
| 预收订金 | 销售单已收的金额，单位应为元。 |
| 定金比例 | 定金单的百分比，单位为 0–100%。 |
| 产品 | 以货号、品名、成分、克重、门幅描述的面料资料。 |
| 产品图片 | 产品的花型原图与缩略图，可在 COS 或本地保存。 |
| 入库记录 | 记录某品名/产品的入库匹数和米数。 |
| 库存台账 | 入库减去订单出库后的聚合结果。 |
| JSON fallback | MySQL 不可用时的服务端文件数据库 `database_fallback.json`。 |
| 浏览器 fallback | localStorage/IndexedDB 中的本地数据或缓存。 |
| 权威数据源 | 发生冲突时被视为最终真实数据的唯一存储。当前项目尚未充分明确。 |
| Repository | 隔离业务服务与 MySQL/文件实现的数据访问接口。 |
| Migration | 可追踪、按版本执行的数据库 schema/数据变更。 |
| COS | 腾讯云对象存储，用于图片文件。 |
