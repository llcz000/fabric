# 项目概览

## 产品定位

Fabric DMS 是一个面料行业内部业务工具，主要服务于开单、打印、产品花型资料和库存台账管理。

当前支持三种单据：

- 样布码单：记录样布寄送、成分、克重、门幅、米数和金额。
- 销售发货码单：记录分匹米数、扣损、单价、金额、收货与结算信息。
- 定金单：记录订单总额、定金比例和客户收货信息。

延伸能力包括产品图库、图片/COS 存储、Excel 导入导出、单据图片导出和库存汇总。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | React 19、TypeScript、Vite 6、Tailwind CSS 4、Lucide Icons |
| 后端 | Express 4、TypeScript、Multer、Zod |
| 数据 | MySQL 8 风格 schema；JSON 文件 fallback；localStorage；IndexedDB |
| 文件与图片 | 腾讯云 COS、本地 uploads、Sharp |
| 表格与导出 | ExcelJS、html2canvas-pro |
| 工具脚本 | TIFF 转 JPG、产品图批量上传、印花试穿实验 |

## 当前成熟度

| 维度 | 判断 | 说明 |
|---|---|---|
| 功能覆盖 | 中高 | 开单、预览、库存、产品库均有完整 UI 路径。 |
| 可构建性 | 良好 | TypeScript 检查和生产构建通过。 |
| 数据一致性 | 偏低 | 多数据源 fallback 缺少明确主从与同步协议。 |
| 安全性 | 不可直接公网发布 | 默认密码、登录限流、上传与 SSRF 边界仍需加固。 |
| 可维护性 | 偏低 | `server.ts`、`App.tsx` 和多个组件过大。 |
| 自动化测试 | 很低 | 没有单元、集成或端到端测试脚本。 |
| 文档 | 已改善 | 本知识库补齐结构与路线图；根 README 仍需重写。 |

## 关键入口

- 前端入口：`src/main.tsx` → `src/App.tsx`
- 后端入口：`server.ts`
- 样式入口：`src/index.css`
- 类型定义：`src/types.ts`
- 构建配置：`package.json`、`vite.config.ts`、`tsconfig.json`
- 运行脚本：`scripts/`
