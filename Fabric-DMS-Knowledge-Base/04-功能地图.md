# 功能地图

## 登录与会话

- 单管理员密码登录。
- Bearer token 存在浏览器 sessionStorage。
- 401 时清理 token 并回到登录页。
- 当前没有用户、角色、权限和明确退出按钮。

## 单据

- 创建、编辑、复制、删除、筛选和预览。
- 三类单据：样布、销售发货、定金。
- 自动编号、客户历史提示、金额汇总。
- 销售支持分匹米数与扣损。
- 支持结清状态。
- 支持打印、PNG、JSON 和 Excel 导出。
- 支持浏览器 JSON 备份导入/导出，但目前不是服务端全库备份。

## 公司与排版

- 公司名、品牌字标/Logo、地址、电话。
- 样布/销售条款与定金条款。
- 微信/支付宝收款码。
- 单据签字栏标签。

## 产品库

- 产品新增、编辑、删除、批量选择。
- 货号、品名、成分、克重、门幅。
- 多图上传、缩略图、灯箱浏览。
- Excel 导入/导出。
- COS 主存储、本地文件降级、IndexedDB 缓存。

## 库存

- 批量录入入库日期、品名、匹数、米数、备注。
- 删除入库记录。
- 汇总入库、出库、结余米数与匹数。
- 当前按品名文本与订单明细计算出库。

## 大盘

- 按单据类型统计数量、米数、金额。
- 面料品名 Top 5。
- 最近开单列表。
- 当前“定金金额”口径需修复，见 [[05-数据模型#定金字段歧义]]。

## 工具脚本

- TIFF 批量转 JPG。
- 按货号将 JPG 批量挂到产品。
- 基于服装蒙版的印花上身效果实验。

## 明确未覆盖

- 多用户和角色权限。
- 审计日志。
- 服务端完整备份与恢复。
- 正式数据库 migration。
- 自动化测试。
- 消息通知、操作撤销、软删除。
- 可靠离线同步。
