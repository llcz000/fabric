# 项目结构

## 顶层目录

```text
D:\fabric
├─ src/                         # React 前端源码
│  ├─ components/              # 业务页面与组件
│  ├─ lib/db.ts                # 产品库 IndexedDB fallback
│  ├─ App.tsx                  # 应用状态、导航、API 与数据映射
│  ├─ index.css                # Tailwind、打印和全局样式
│  ├─ main.tsx                 # React 入口
│  └─ types.ts                 # 前端领域类型
├─ server.ts                   # Express、数据库、API、文件、COS、Vite
├─ scripts/                    # TIFF、产品图片、印花试穿工具
├─ docs/                       # 历史架构审计与临时资料
├─ agent/skills/               # Google Stitch 本地技能包
├─ dist/                       # 可再生成构建产物
├─ node_modules/               # 可再安装依赖
├─ .transformers_cache/        # 相似图实验模型缓存
├─ tmp/                        # 相似图/试穿实验产物
├─ uploads/                    # 运行时上传与本地产品图片
├─ template/                   # 运行时 Excel 模板
├─ Fabric-DMS-Knowledge-Base/  # 本 Obsidian 知识库
└─ .planning/                  # 本次审计工作记录
```

## 前端组件职责

| 文件 | 主要职责 | 规模/关注点 |
|---|---|---|
| `App.tsx` | 登录、API、数据映射、导航、全局状态 | 约 877 行，需拆分 |
| `DocumentEditor.tsx` | 三类单据录入、分匹、金额计算 | 约 1079 行，桌面/移动逻辑重复 |
| `DocumentPreview.tsx` | 打印、PNG/JSON/Excel 导出 | 约 707 行，最大懒加载模块 |
| `DocumentList.tsx` | 筛选、统计、备份导入导出 | 约 699 行 |
| `ProductLibrary.tsx` | 产品 CRUD、图像、批量操作、Excel | 约 674 行，多数据源缓存复杂 |
| `InventoryManager.tsx` | 入库录入和库存台账 | 约 378 行 |
| `CompanyProfileEditor.tsx` | 公司、条款、Logo/收款码配置 | 约 346 行 |
| `StatsDashboard.tsx` | 单据与品名统计 | 约 254 行 |
| `ErrorBoundary.tsx` | 渲染异常兜底 | 已存在 |

## 后端职责块

`server.ts` 约 2,248 个行号范围，包含：

1. 环境变量、目录与 Express 中间件。
2. 简单管理员登录和内存 token。
3. 图片代理与 SSRF 防护。
4. Multer 上传策略。
5. MySQL 建表、增量列与启动修复。
6. JSON 文件 fallback。
7. 腾讯云 COS。
8. 公司、订单、模板、库存、产品 API。
9. Excel 读写和图片处理。
10. Vite 开发中间件与生产静态服务。
