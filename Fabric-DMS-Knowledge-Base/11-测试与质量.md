# 测试与质量

## 统一图片资产测试

- test:image-assets：图片资产后端单元/集成测试 + 前端客户端协议测试。
- test:image-export：样布码单导出 Blob 准备/清理测试。
- test:image-assets:smoke：启动 dist/server.cjs 的真实 HTTP 冒烟（登录、公司图片内容端点、脱敏、feature-off 兼容）。
- test:security：生产安全冒烟（含图片资产禁用守卫、解析器隔离、未授权、脱敏探测）。
- test:all：lint + test:unit + build + test:security + test:image-assets:smoke 的一站式验证。

对账与故障注入覆盖：引用计数漂移重算、缺失对象标记 degraded、孤儿候选枚举（仅列表不删除）、stale job 恢复（locked_at 超 5 分钟）、worker 启动恢复、结构化日志脱敏（不含 Authorization/SecretKey/sign/Cookie）。已知 test:unit 存在 tmp/tests 临时目录竞态，需隔离重跑缺失的测试入口。

## 建议测试金字塔

### 单元测试

- 金额、扣损、定金、分匹米数计算。
- 前后端 DTO 映射。
- 中文大写金额。
- 库存台账聚合。
- SSRF IP 判断与 URL 校验。
- 文件路径根目录约束。

### API 集成测试

- 登录成功/失败/限流/token 过期。
- 订单创建、修改、删除事务回滚。
- Zod 校验返回 400 而非 500/未处理异常。
- MySQL 异常不静默切换到旧数据。
- 产品图部分失败的补偿。
- 批量删除只删除精确 ID。
- Excel 导入事务与错误报告。

### E2E

- 登录 → 开单 → 保存 → 预览 → 再编辑。
- 桌面与移动端扣损计算一致。
- 后端删除失败时 UI 不消失。
- 定金单比例、金额、条款在编辑/预览/Excel/大盘一致。
- 产品新增、多图、删除单图、批量删除。
- 备份导出与服务端恢复。
- 打印和 PNG/Excel 导出。

## CI 建议

```text
install → typecheck → unit → integration → build → e2e smoke
                         ↘ secret scan / dependency audit
```

## 质量门槛

- 新业务计算必须有单元测试。
- 新 API 必须有成功、校验失败、未授权与持久化失败测试。
- 数据迁移必须有向前迁移、幂等与备份恢复说明。
- 不以“构建通过”替代业务验收。
