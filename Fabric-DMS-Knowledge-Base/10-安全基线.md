# 安全基线

## 当前风险排序

| 等级 | 风险 | 当前状态 |
|---|---|---|
| 严重 | 明文云凭证落在项目文件 | 已发现，需立即轮换 |
| 严重 | 缺少管理员密码时使用固定默认密码 | 已修复并有冒烟测试 |
| 高 | 登录无速率限制/锁定 | 已加入登录/API 限流 |
| 高 | 公开 uploads + 允许 SVG | 已鉴权 uploads，并拒绝 SVG |
| 高 | 图片代理 SSRF 防护可绕过 | 已完成逐跳与响应限制 |
| 高 | 多数据源静默 fallback 影响数据完整性 | 未修复 |
| 中 | token 无过期、角色、身份与审计 | 已加 12 小时过期；角色与审计待补 |
| 中 | 产品文件与数据库变更非原子 | 未修复 |
| 中 | 部分接口缺少完整输入 schema | 部分修复 |
| 中 | 本地路径缺少 uploads 根目录约束 | 产品图片读取已修复；其他文件路径继续审计 |

## 凭证处理

- [ ] 轮换所有已暴露凭证，而非只改文件。
- [ ] 检查云访问日志与异常对象/数据库操作。
- [ ] 使用最小权限、短期凭证或服务角色。
- [ ] CI 加 secret scanning。
- [x] `.env.example` 仅保留占位符。
- [ ] 文档、截图、日志和测试数据不含真实凭证。

## 认证

- [x] 无 `ADMIN_PASSWORD` 时启动失败。
- [x] 单管理员密码从受控 secret 读取并使用恒定时间比较。
- [x] 登录端点单独按客户端 IP 限流；成功登录不计入失败额度，账户锁定仍待后续评估。
- [x] 普通 API 独立限流，健康检查不占用业务额度。
- [x] 仅信任本机反向代理的客户端 IP 转发信息。
- [x] token 有过期时间并可通过退出撤销；定期清理待补。
- [x] 提供明确退出功能。
- [ ] 公网场景优先采用成熟 session/OIDC，而非自制 token 集合。

## 上传

- [x] 按路由区分图片和 Excel 模板，不共用宽松白名单。
- [ ] 校验实际文件签名，不只信任扩展名/MIME。
- [x] 默认拒绝 SVG。
- [ ] 文件名服务端生成，不使用原名覆盖模板。
- [ ] 设置大小、像素、页数、解压后体积和处理超时限制。
- [ ] 成功/失败后清理临时文件。
- [x] 产品图片本地路径在 `resolve` 后验证仍位于 uploads 根目录，并校验图片属于路由中的产品。

## SSRF

- [x] 只允许 `https`；域名 allowlist 可按部署场景追加。
- [x] DNS 解析失败拒绝，而不是放行。
- [x] 拒绝 loopback、link-local、私网、组播、保留 IPv4/IPv6。
- [x] 每次重定向重新解析和校验。
- [x] 禁止非图片 Content-Type，限制响应大小和超时。
- [x] 不回传上游敏感响应头。

## 数据与运维

- [ ] 数据库用户最小权限，不使用 root。
- [ ] 生产只允许 HTTPS。
- [ ] 添加 Helmet/安全头和明确 CSP。
- [ ] 日志脱敏并有 request ID。
- [ ] 删除/导入/配置变更写审计日志。
- [ ] 定期备份并演练恢复。
- [ ] 对依赖运行审计和升级策略。

## 上线门槛

所有“严重/高”项关闭；至少有登录限流、上传拒绝测试、SSRF 私网测试、未登录 API 测试、备份恢复演练和 secret scan 报告。
