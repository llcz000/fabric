# 安全基线

## 统一图片资产安全

- 私有 COS 为唯一权威文件存储，客户端只获得最小权限、短时有效的单对象上传/读取授权，不能选择正式 object key。
- 服务端用 Sharp 校验真实内容并计算 SHA-256，不信任客户端 MIME/扩展名/尺寸/哈希。
- 所有资产读取都经过业务关联鉴权，知道资产 ID 或哈希不等于拥有访问权；不提供任意 URL 代理。
- 生产不自动回退本地存储；签名 URL 仅存运行时，不落库、不进 IndexedDB、不进日志。
- 结构化日志经 observability.ts 脱敏（redactLogText / safeLogLine），丢弃 authorization/cookie/secret/token/sign 等字段并脱敏密文。
- 新增数据库记录、业务 JSON 响应与 IndexedDB 记录均不保存整张 Base64 图片。

## 凭证处理

- [ ] 轮换所有已暴露凭证，而非只改文件。
- [ ] 检查云访问日志与异常对象/数据库操作。
- [ ] 使用最小权限、短期凭证或服务角色。
- [ ] CI 加 secret scanning。
- [x] `.env.example` 仅保留占位符。
- [ ] 文档、截图、日志和测试数据不含真实凭证。

## 认证

- [x] 无 `ADMIN_PASSWORD` 时启动失败。
- [x] 单管理员密码从受控 secret 读取并使用恒定时间比较。
- [x] 登录端点单独按客户端 IP 限流；成功登录不计入失败额度，账户锁定仍待后续评估。
- [x] 普通 API 独立限流，健康检查不占用业务额度。
- [x] 仅信任本机反向代理的客户端 IP 转发信息。
- [x] token 有过期时间并可通过退出撤销；定期清理待补。
- [x] 提供明确退出功能。
- [ ] 公网场景优先采用成熟 session/OIDC，而非自制 token 集合。

## 上传

- [x] 按路由区分图片和 Excel 模板，不共用宽松白名单。
- [x] 图片通过 Sharp 解码并核对实际格式、MIME 与扩展名；Excel 通过 ExcelJS 解析验证。
- [x] 默认拒绝 SVG。
- [x] 文件名由服务端生成，不使用原名覆盖模板。
- [x] 上传限制 10 MB，图片限制 4000 万像素；Excel 页数、解压体积与处理超时仍待补。
- [x] 校验/业务失败、Excel 导入完成、COS 上传成功后清理临时文件；本地持久化文件与有效模板保留。
- [x] 产品图片本地路径在 `resolve` 后验证仍位于 uploads 根目录，并校验图片属于路由中的产品。

## SSRF

- [x] 只允许 `https`；域名 allowlist 可按部署场景追加。
- [x] DNS 解析失败拒绝，而不是放行。
- [x] 拒绝 loopback、link-local、私网、组播、保留 IPv4/IPv6。
- [x] 每次重定向重新解析和校验。
- [x] 禁止非图片 Content-Type，限制响应大小和超时。
- [x] 不回传上游敏感响应头。

## 数据与运维

- [ ] 数据库用户最小权限，不使用 root。
- [ ] 生产只允许 HTTPS。
- [ ] 添加 Helmet/安全头和明确 CSP。
- [ ] 日志脱敏并有 request ID。
- [ ] 删除/导入/配置变更写审计日志。
- [ ] 定期备份并演练恢复。
- [ ] 对依赖运行审计和升级策略。

## 上线门槛

所有“严重/高”项关闭；至少有登录限流、上传拒绝测试、SSRF 私网测试、未登录 API 测试、备份恢复演练和 secret scan 报告。
