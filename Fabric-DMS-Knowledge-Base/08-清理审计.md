# 清理审计

> [!info] 本次仅给出清理建议
> 没有删除现有项目文件。用户工作树中已有修改与删除状态，均保持不动。

## A. 可再生成，可优先清理

| 路径 | 约占用 | 理由 | 恢复方式 |
|---|---:|---|---|
| `node_modules/` | 620.63 MB | 安装产物 | `npm.cmd install` |
| `dist/` | < 1 MB（扫描时） | 构建产物 | `npm.cmd run build` |
| `.transformers_cache/` | 244.12 MB | 模型下载缓存；主应用未引用 | 运行实验时重新下载 |

清理 `.transformers_cache` 前确认仍是否需要 `tmp/search_test` 的离线实验；删除虽安全，但重新下载耗时和流量较大。

## B. 确认用途后清理或归档

| 路径 | 建议 |
|---|---|
| `tmp/`（63.11 MB） | 相似图搜索和试穿实验；若不继续研发，整体归档到项目外或删除。 |
| `request.json` | 临时模型请求样例，主应用无引用，可删除或移入 fixtures。 |
| `scripts/generate_mockup.py` | 与 DMS 主应用未集成；保留则移入 `experiments/tryon/`。 |
| `agent/skills/` + `skills-lock.json` | 仅 Stitch/设计代理工作流需要；不用 Stitch 时可从主仓库移除。 |
| `LAYOUT_ANALYSIS.md`、`QR_SIZE_DEBUG.md` | 有历史价值，建议归档到知识库/ADR，而非散落根目录。 |
| `CONCEPTS.md` | 内容较少且与本知识库重复，可合并进 [[12-术语表]] 后删除原文件。 |
| `metadata.json` | AI Studio 元数据；不再用 AI Studio 时可移除。 |
| `.claude/settings.local.json` | 个人本机配置，应忽略版本控制；是否删除由使用者决定。 |
| `.idea/` | IDE 状态；通常从 Git 移除并忽略，团队共享检查配置需另行确认。 |

## C. 重复/漂移文件，需要合并后再删

| 文件组 | 处理方式 |
|---|---|
| `.gitignore` 与 `gitignore` | 合并双方规则到 `.gitignore`，验证后删除无点文件。 |
| `.env.example` 与 `env.example` | 保留唯一 `.env.example`，包含 `ADMIN_PASSWORD` 等实际键，全部使用占位符。 |
| `html2canvas` 与 `html2canvas-pro` 依赖 | 源码只引用 pro；验证兼容后移除普通版。 |

## D. 候选移除依赖

主应用/正式脚本没有代码引用：

- `@google/genai`
- `@xenova/transformers`（仅 tmp 实验引用）
- `html-to-image`
- `html2canvas`（使用的是 `html2canvas-pro`）
- `motion`

`express-rate-limit` 当前没使用，但 [[10-安全基线]] 建议立即接入，因此不建议先删除。

## E. 敏感文件

`docs/yxm` 含明文云凭证。正确顺序：

1. 立即在云平台轮换/禁用旧凭证。
2. 检查访问日志与异常使用。
3. 删除明文文件并完善 ignore/secret scanning。
4. 检查 Git 历史、备份、聊天和部署包是否传播。

不要把旧值复制到 issue、知识库、提交信息或终端日志。

## F. 不可直接删除

| 路径 | 原因 |
|---|---|
| `.git/` | 仓库历史与版本控制元数据；绝不能整目录删除。 |
| `uploads/` | 可能是 COS 不可用时的真实业务图片。当前为空不代表以后可删。 |
| `template/` | 可能保存业务 Excel 模板。当前为空不代表以后可删。 |
| `database_fallback.json` | 若系统曾用 fallback，可能包含真实单据；必须先核对和备份。 |
| `.env` | 含本机运行配置；不提交，但删除会影响运行。 |

## G. Git 体积

`.git` 约 225.57 MB，明显大于当前可达源码。大对象多为无路径映射的悬空模型/实验 blob。推荐在备份、确认 reflog 和团队协作状态后，再决定是否执行对象清理。不要把 `git gc --prune` 当作普通缓存删除。
